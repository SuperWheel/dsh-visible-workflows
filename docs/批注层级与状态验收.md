## 本次规则

- 批注的添加引用菜单仅列当前层节点。修改内部节点时，先进入对应子流程；子流程显示本层局部编号，如 `a-1`，不拼接父编号。
- 菜单按稳定节点 ID 去重，排除已选节点；已有显式引用保留，节点身份及变量引用不变。

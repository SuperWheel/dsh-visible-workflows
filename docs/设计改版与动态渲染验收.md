# 设计改版与动态渲染验收

日期：2026-10-14，Asia/Shanghai。此记录对应 [DESIGN.md](../DESIGN.md) 制定后实施的界面改版、视口裁剪及缩略图；旧的 MVP 验收记录保留为历史。本轮先在官方 Harness Web 验证，再更新官方 Desktop 插件。

## 1 已交付

- 顶部只保留标题与保存状态；注释操作和执行操作为右上角两个圆角浮动模块。选中只显示边框高亮，没有勾选图标。
- 工作流设置迁入 Harness 原生“设置 → 工作流”。角色预设仍仅包含提示词，节点通过下拉框选择，管理入口可直接打开原生设置。
- 移除插件重复的侧栏展开按钮，沿用宿主原生全屏/退出全屏；底部画布缩放继续保留。
- 节点菜单、工具分类、排序菜单、输入框、下拉框、配置面板、运行记录、预设与询问弹窗统一字号、间距、圆角及主题色。
- 节点按真实宽高布局，整理与复制避开容器和较长的分支节点。
- 只挂载可视区及 200px 屏幕缓冲区内的节点、便签与连线；跨越视野的连线仍显示。正在聚焦的一个节点保留以免键盘焦点丢失，全选不会迫使全图挂载。
- 平移、缩放和拖动按浏览器动画帧合并更新；连线使用 ID 索引，不再逐边扫描完整节点数组。松手时提交最后位置，不能丢失最后一段拖动。
- 右下角位图缩略图显示完整流程和当前视野，支持点击、拖动、方向键、居中及收起/展开。窄画布首次默认收起，之后尊重用户选择。

## 3 官方 Harness Web 实测

环境：本机 macOS arm64，Codex 内置浏览器，官方 Harness Web 0.2.0-rc.2，`http://127.0.0.1:5188`，隔离配置 `.cache/harness-web-test`。页面 1041×977 CSS px；性能画布 761×909 CSS px，100% 缩放。未测 FPS、长任务分布或硬件间差异，不宣称固定帧率或百分比加速。

| 操作 | 已观察结果 |
| --- | --- |
| 200 个混合节点、199 条边的初始视野 | DOM 仅挂载 **6 节点、9 连线**；缩略图仅一个 Canvas 元素。 |
| 点击缩略图中部 | 视野移动到原先屏外的节点，挂载 **12 节点、13 连线**；总节点数仍为 200。 |
| 缩略图拖动、方向键、收起与展开 | 视野同步移动；收起后出现展开按钮，再次展开恢复。 |
| 导出完整图 | 页面导出的 SVG 包含 **200 个节点**，包括最后的“200 · 输出”；当前离屏节点没有丢失。 |
| 字号与尺寸 | 节点菜单项字体 14px、行高容器 40px；搜索输入容器 36px；执行组件按钮高 32px、字体 13px。 |
| 角色预设管理 | 新增后显示卡片，再次编辑保存后显示更新提示词；节点“管理角色预设”直接进入原生工作流设置。 |
| 独立运行 | 循环流程实际输出“最终计数：3；执行轮数：3”。另一个历史测试流程含未连接节点，执行被正确阻止，未误报成功。 |
| 深色主题 | 配置面板、表单、选中边框与画布实看；测试后恢复“跟随系统”。 |

验收图使用 [生成脚本](../scripts/create-performance-fixture.ts)，仅允许写入隔离 Web 配置。它包含多种节点外观，不用于执行模型任务。数据保留在测试环境中供复核。

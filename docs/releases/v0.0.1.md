# dsh-visible-workflows v0.0.1

首个公开预览版本，为 DeepSeekHarness 提供可视化工作流的创建、编辑和执行能力。

## 本次发布

- 工作流管理页面、对话侧栏画布、节点与工具菜单、便签、节点引用及撤销重做。
- Graphon 核心执行、分支、循环、迭代、人工介入及运行记录；默认使用 DSH 中已配置的模型。
- 主 Agent 可在授权范围内生成和修改流程，保护用户固定节点。
- 工作流和 CLI Worker 使用宿主侧栏标签切换，工作流专用布局样式限定在工作流激活期间。
- macOS Apple Silicon 预构建 Python/Graphon 运行环境，无需用户手动安装 Python。

## 安装

适用宿主：DeepSeekHarness 0.2.0-rc.2；适用平台：macOS Apple Silicon。

下载 `dsh-visible-dynamic-workflows-0.0.1-macos-arm64.tgz`，在 DSH「插件 → 添加插件」中输入下载文件的绝对路径，按宿主提示启用或重启。`SHA256SUMS` 可用于检查下载文件完整性。

仓库名为 `dsh-visible-workflows`；为兼容已有安装，包名和宿主插件标识保留 `dsh-visible-dynamic-workflows`。GitHub 自动生成的源码压缩包不是插件安装包。

## 已知边界

这是早期预览版，尚未完成 Dify 全量对标。自动触发器、发布与部署、完整 DSL 往返兼容、多人协作、Chatflow 专用能力和 Dify 插件生态完整适配尚未完成。模型与外部工具需要宿主中已有的配置和权限，本次发布检查不包含真实模型付费调用。Windows 和 Intel Mac 暂未提供经过实机验证的运行环境。

详细功能及限制以仓库 README 和对标清单为准。

## 发布验证

使用独立目录和独立安装的依赖完成完整构建、TypeScript 类型检查，29 个测试文件、268 项测试全部通过。仓库提交 pnpm 锁定文件；构建与测试不依赖相邻 CLI Worker 项目的 node_modules。

# 批注与统一侧栏验收

2026-10-16。本次为界面和导航修正，不代表完成 Dify 全量对标；本次验收未发送 Agent 消息，未调用付费模型。

## 实施规则

- 运行记录下拉和状态摘要均为通用 **32px** 高，中间 **12px** 间距；额外模型信息单独展示。
- 修改批注改为贴近目标的轻量浮层：蓝色序号、固定宽节点标签、圆角输入、图标提交。悬停标签显示尾部叉并渐隐文字；删除不改变标签尺寸。
- `…` 展开溢出节点，`+` 添加节点；两者均有顶部搜索。溢出行只提供尾部删除，添加行只显示尚未引用节点，含内部流程节点。
- 引用以稳定 ID 保存；编号及显示名称可以随结构变化。修改正文或引用都更新同一条批注，保留注释序号；提交仅保存聊天草稿。
- 左侧工作流入口、管理卡片和聊天引用统一使用原生侧栏；放大/收回交给宿主，返回箭头仅返回侧栏主页。当前会话、草稿及其他插件布局不被工作流主页面替换。
- 不再观察宿主全屏变化并将其转换为工作流主区域。入口仅捕获本插件对应的原生导航行，卸载时移除监听。
- 无有效关联会话时不显示其他会话的批注。跨会话协作目标若有未提交工作流需求，拒绝覆盖并保留双方草稿，可先完成需求或选择新对话。

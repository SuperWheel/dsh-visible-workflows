# 浮动导航与三级按钮验收

日期：2026-10-16。依据：[DESIGN.md 第 20 节](../DESIGN.md#20-浮动导航与分支卡片2026-10-16)。版本保持 v0.0.1。

## 最终规则

- 移除全宽白色标题栏。返回按钮与标题分开浮动，标题只显示一行，超长省略；保存状态改为小状态点，悬停或聚焦查看状态及版本。
- 返回、标题、所选节点操作组、执行组均为 38px，顶边一致。
- 根据完整操作的实际宽度选择三级呈现：文字 → 28px 图标 → 执行/停止加展开菜单。先收窄标题，图标组也放不下时才进入菜单，不换成多排。
- 运行记录和节点配置只遮挡下方画布，不参与顶部宽度判断。完整宽度由保留的文字自然尺寸测量，不受当前隐藏状态影响；执行控件只渲染一次。
- 条件分支、分类器、人工介入改为内缩浅灰条目，删除跨整卡横线；保留原 32px 出口槽位、节点尺寸及所有端口身份。

## 真正 DeepSeekHarness Web 验收

使用真实宿主 `http://127.0.0.1:5188/`，没有使用独立预览壳。

| 项目 | 实测结果 |
| --- | --- |
| 单行与对齐 | 导航、返回、执行组顶边一致，高度均为 38px；标题实际内容宽度大于显示宽度时显示省略号。 |
| 文字态 | 1040.5px 画布中显示完整文字与所选数量，操作组没有换行。 |
| 图标态 | 360.5px 画布中显示注释、复制、删除、Agent、执行五个 28px 图标按钮；名称保留在 Tooltip / aria-label。 |
| 收起态 | 临时 320px 视口、319.5px 画布中仅显示执行与展开。菜单包含 Agent、添加注释、复制、删除；测试后已恢复视口。 |
| 运行记录 | 打开前后保持原响应状态和顶边，不因面板宽度切换状态。 |
| 注释菜单 | 添加注释会进入放置状态并聚焦画布，Esc 可取消；未生成永久测试批注。 |
| 分支卡片 | 人工介入三行的中心与真实端口中心误差小于 0.001px，无全宽边框；条件分支显示实际 `vars.count ≥ 3`，面包屑返回正确。 |

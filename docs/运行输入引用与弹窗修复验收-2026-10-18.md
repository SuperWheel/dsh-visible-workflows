# 运行输入引用与弹窗修复验收

> 2026-10-21 说明：工作流预算系统已于 2026-10-20 移除（见 [S12](<../doc/workflow-manual/规划引擎/设计/tasks-规划提速与上下文复用.md>)）。本文涉及预算问答、额度、增额或费用的内容仅为历史记录，不再执行；Token 用量只作性能计量保留。

## 1、问题与根因

工作流「入口联动验收-20261018」（`f090b1e3-92b6-4b45-804d-b629309ac5eb`）的三次失败记录均显示输入节点成功，模板节点失败。最近一次输入为“哈哈”，输入节点已产生 `name` 字段，数据没有在弹窗提交时丢失。

模板输入和最终输出使用了 `{{#节点ID.字段#}}`。该写法不是本项目当前 JSON 标准中的变量语法；运行时把 `#` 作为节点标识的一部分，因而无法找到上游结果。当前语法为 `{{节点ID.字段}}` 或 `{{input.字段}}`；模板 `inputs` 映射到模板局部变量后使用 `{{name}}`。

现有工作流的两处引用已通过画布编辑并保存。节点 ID、连线、姓名输入和问候文字均保留。重启前当前画布已保存为 v10。

## 2、修复范围

1. 规划提示明确当前变量语法和输入、模板的真实输出字段，禁止 `#` 包裹。
2. 候选校验区分无效引用与越权引用：无效语法或不存在的必需生产节点返回 `INVALID_REFERENCE`，进入现有修复重试；真实跨作用域访问仍阻止发布。
3. `default`、`is defined` 等可选值语义保留；条件守卫只覆盖对应路径与分支，不能通过任意 `if` 块绕过必需引用检查。
4. 黑色执行按钮恢复 28 px 高、6 px 圆角；图标模式为 28 × 28 px，外层浮动组件仍为 38 px。
5. 运行输入弹窗沿用节点菜单的字号、间距与控件参数：区块间距 16 px、字段卡片内边距 12 px、标签间距 8 px、控件和底栏按钮高 32 px。长表单只滚动正文，标题与底栏固定。

# Dify 便签参考与本轮适配

核对日期：2026-10-15。仅只读检查官方固定版本 `1.17.1` 源码，没有打开或修改用户的 Dify 自动保存流程。

| 可核对的官方行为 | 本轮适配与差异 |
| --- | --- |
| 便签是带浅边框、阴影和顶部色条的纸张卡片；尺寸来自节点数据。 | 采用 DeepSeekHarness 字体、边框和阴影；DESIGN 默认 280×180、圆角 10px，不把本项目尺寸称为 Dify 默认值。 |
| 选中时显示卡片上方工具条；提供主题、复制、重复、删除和作者显隐。 | 本轮紧凑工具条重点为颜色、连接节点、删除；复制/重复、作者显示以及完整富文本仍需按全量矩阵逐项补齐。 |
| 原生 `NodeResizer` 最小宽 240px、最小高 88px；正文区滚动；选中编辑时阻止画布拖动/平移。 | 本轮缩放与编辑需形成一次撤销事务；具体最小尺寸服从本项目 DESIGN，并明确与 Dify 的差异。 |

以上行为直接来自 [官方 note-node/index.tsx](https://github.com/langgenius/dify/blob/1.17.1/web/app/components/workflow/note-node/index.tsx)，本轮成功读取其正文。

官方主题枚举为 `blue / cyan / green / yellow / pink / violet`，便签类型包含文本、主题、作者和作者显隐。本轮 DESIGN 使用柔和黄/蓝/绿/紫/中性色，是宿主视觉适配，不能宣称颜色选项与 Dify 完全一致。[官方 note-node/types.ts](https://github.com/langgenius/dify/blob/1.17.1/web/app/components/workflow/note-node/types.ts)。

本轮检查的两个官方文件没有展示“便签绑定某个业务节点”的字段或连接处理器。因此，**稳定节点 ID 连接、虚线说明关系、跟随节点、删除节点后解绑定**记为本项目新增设计；虚线不参与工作流执行。该结论仅限已检查源码，不把未发现当成已证明整个 Dify 仓库不存在类似能力。

双击进入原位编辑、拖动手柄位置、具体颜色值、连接/跟随以及默认尺寸都以 [DESIGN.md 第 9 节](../DESIGN.md#9-注释便签与浮动面板修订2026-10-15) 为本项目合同。Dify 富文本工具条的 `command.tsx`、`hooks.ts` 本轮抓取失败，未据此重复宣称已核对全部格式操作；先前需求基线见 [Dify画布能力对照.md](Dify画布能力对照.md) 的 CAN-13/14。复刻完整富文本仍需单独读取与行为验收。

验收应覆盖新增、编辑、删除、拖动、缩放、换色、连接/解除连接、节点移动跟随、节点删除解绑定、撤销重做、保存重开、工作流复制和视图导出；注释草稿和便签的存储及生命周期保持分离。

## 1、最终实现

表 1：右侧卡片规则

| 对象 | 当前规则 |
| --- | --- |
| 定位与宽度 | 复用“补齐缺失值”的 `.vdw-editor-dock`：距右侧 12px，顶部沿用原导航高度计算，宽度 `min(360px,100% - 24px)`。 |
| 视觉强调 | 轻蓝背景和边框、“修改请求”标记、待确认数量、明确说明及原生 primary“查看修改”按钮。卡片内边距与圆角均 12px，按钮 32px 高。 |
| 通知堆叠 | 修改请求在前、缺失值清单在后，间隔 8px；两者处于同一可滚动通知区域。打开节点配置或运行详情时，通知区域最多占右侧区域的 36%。 |
| 缩略图与画布 | 复用缺失值清单的底部预留；仅显示通知不移动缩略图、不触发节点自动平移。详情面板继续沿用原有避让行为。 |
| 提醒方式 | 卡片出现时淡入 160ms，遵守减少动态效果；保留礼貌级屏幕阅读器提示，不闪烁、不抢焦点、不自动打开弹窗。 |
| 查看与完成 | “查看修改”打开原提案审阅弹窗。接受或拒绝后按真实 pending 列表更新数量；最后一项处理完后卡片消失。 |
| 撤回的逻辑 | 删除顶部提示容器、额外高度累加、节点菜单和管理菜单的下移样式，以及溢出菜单的自定义锚点。 |

## 3. 交互和信息层级观察

### 节点与右侧面板

- 节点标题本身是可聚焦按钮；手模式下点击卡片空白/主体未必打开配置，点击标题可稳定打开。
- 配置头、用途描述、设置/上次运行构成固定头部，下面的字段独立滚动；因此长提示词不会把关闭按钮推走。
- 面板中的标题直接是可编辑字段，常态透明；描述可以为空，空状态展示「添加描述…」。
- 节点右键时面板可收起，菜单出现在节点附近。不能假设右键之后右侧模型选择还可用。
- 模型下拉按提供方分组，选中模型有蓝色标识；搜索与提供方设置保持固定层级。插件中的节点多选仍遵守用户确定的“仅边框高亮”，不要引入节点勾选框。

### 提示词、说明与高级配置

- SYSTEM/USER 卡片头集中角色、计数和小图标动作；正文与变量 chip 放在连续灰面内。
- 标题旁的问号是说明入口，按钮有具体可读辅助名称；重要字段还同时保留文字说明。
- 本轮已读到上下文、视觉、异常处理等帮助按钮的辅助说明；没有成功取得独立 `role=tooltip` 浮层，因此不将浮层的尺寸、延时或触发方式记为已核验。
- 高级选项采用标题行 + 右端开关/下拉；输出变量展开后是「变量名 / 类型 / 说明」的轻量列表，不是嵌套大卡片。
- 异常处理下拉实际包含「无」「默认值」「异常分支」，每项附一行说明。观察未改变当前「无」选项。
- 开始节点输入字段是紧凑摘要行；结束节点是输出名与变量引用并排。下一步区带小节点图标、细连线、目标摘要/虚线添加区。

### 便签

- 默认仅显示内容和淡色顶条；hover 可出现角落 resize 提示。选中时浮动条放在便签上方，并显示颜色、字号、加粗、斜体、删除线、链接、列表和更多。
- 本插件当前采用安全轻量 Markdown 编辑，已实现标题/粗体/列表/行内代码，并保留连接节点这一产品特性。它与 Dify 的所见即所得富文本并不等同，不能声称已有全部富文本工具。
- 便签的“连接节点”与“引用节点发给 Agent”是不同动作。保留本产品用户定义的绑定、移动、自动整理及撤销规则。

## 4. 本轮直接吸收的设计建议

1. 所有面板输入、模型摘要、提示词组件使用相同浅灰层，白色仅用于主面板和变量 chip 等更小层次。
2. 主内容的字号维持 13–14px，面板标题 16px，说明 12px；每个层级只使用少数字号和一致行高。
3. 把说明入口收进字段名旁，把多数图标动作收进卡片头；需要持续可见的错误/限制保留正文。
4. 标题原位编辑；固定节点用小锁切换，避免增加两行独立字段。
5. 菜单保持 32–36px 行高，组标题弱化；工具目录按提供方展开具体操作，辅助来源文字比操作名称更淡。
6. 便签保留独立纸面，操作浮动在外。导出图要与画布的文本格式一致，不能把 Markdown 标记重新输出为正文。

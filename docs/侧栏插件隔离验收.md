# 侧栏插件隔离验收

日期：2026-10-16。

## 根因与修复

桌面原版本复现：工作流与 CLI Worker 分栏时点击 CLI Worker 的全屏按钮，会跳转到工作流主页。工作流原先只检查自身可见和共享 fullscreen 状态，误接管宿主导航。

新增 sidebar-presentation 的完整归属判断：会话、当前活动标签、命令目标、停靠位置、唯一工作流标签，以及由非全屏到全屏的真实变化。共享侧栏、分栏、浮窗及后台标签不触发工作流主页面跳转。仍支持两个插件共用侧栏标签，不强制分栏。

## 验证

- typecheck、build 通过；29 文件、268 测试通过，含 21 个隔离回归案例。
- 真正 DSH Web：使用官方宿主，同时加载现有 CLI Worker。单栏标签切换、全屏、分栏、退出全屏、工作流主页返回均通过。CLI root 为 flex，标题 21px；遍历工作流样式没有命中 CLI Worker DOM 的选择器。
- 桌面：原复现路径在更新后不再抢占；重启后重复全屏/退出、同栏标签切换、全局工作流主页返回，CLI 样式正常。
- 桌面另观察到一次 CLI 样式未生效，热更新工作流后仍存在，重启 DSH 后恢复。同样操作未再复现；未把该独立样式问题声称为已确定根因。未修改 CLI Worker 源码或任务数据。
- 没有发送真实模型任务；没有验证全部第三方插件和 Windows。

## 本次修订

- 取消整体白色卡片：浮层和引用容器透明，无边框、内边距和整体阴影。仅评论输入使用白色/宿主主题胶囊，蓝色注释序号在输入旁独立显示。
- 节点胶囊只显示编号，完整名称保留在悬停说明及搜索结果中。编号、`…`、`+` 分别拥有背景、边框和圆角，间距 6px；节点为 64×28px，两种菜单入口为 28×28px，边框 1px、圆角 24px，并显式使用 `corner-shape: round`。
- 输入从一行开始，自适应最多五行；胶囊最小高度 50px，多行时保持 24px 圆角。发送按钮为 34×34px 蓝色圆形，复用宿主业务蓝和白色箭头；Web 实测蓝色为 `rgb(65, 118, 230)`，与宿主一致。
- Enter 提交到聊天草稿，Shift+Enter 换行；中文输入法组合输入及 229 键码不触发误提交。发送聊天消息后 Agent 才会处理。
- 保留多条注释切换、编辑、删除，以及节点引用搜索、溢出和增删。引用使用稳定节点 ID；空引用禁止保存，操作失败保留草稿。删除、查看工作流、关闭使用小型次要图标。

## 已验证的 Web 行为

在真正的 DeepSeekHarness Web 中完成：

- 实测独立胶囊尺寸、圆角、边框和间距；确认外层透明且没有整体白色垫板，发送按钮与宿主同色同尺寸。
- 搜索节点、移除引用并重新添加，目标和内容在草稿中保持一致。

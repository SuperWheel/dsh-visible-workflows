# 工作流第三轮截图与动效验收

日期：2026-10-17。范围：用户最新 7 张截图及统一动效要求；设计基线为 [DESIGN.md 第 24 节](../DESIGN.md)。

## 本轮实现

1. 首页移除归档、数量、刷新整行；归档入口收进状态筛选。固定筛选区下方增加分隔线，列表滚动时淡入阴影，回顶时淡出。
2. 首页模板/导入选中页签与正文白底相连；消除原生 headless Modal 的默认 gap、padding。导入框为宽高 4:3，采用浅主题底色及虚线边界，正文独立滚动。
3. 导出压缩顶部空白；JSON 复用节点 CodeEditor，支持行号、语法高亮、复制及展开，紧凑和展开状态都只读。
4. 保存和另存为合为一个浮动按钮框；另存为改为保存图形加号，保留原快捷键和保存生命周期。画布响应式测量按完整按钮组计算。
5. 运行详情移除“按快照重跑”入口。历史运行详情、暂停、继续和恢复审阅保留原逻辑。
6. “可调用工具”及帮助按钮放入工具选择卡片内部；搜索、筛选、240px 滚动区和统计共用卡片边界。
7. 长待处理清单在缩略图上方预留 12px；展开/收起缩略图时调整清单可用高度。窄配置面板保留缩略图，矮窗口的详情溢出受裁剪且可滚动；缩略图导航以侧栏下方真正可见的区域定位。

## 动效与资源管理

- 菜单、浮层、对话框统一 160ms 淡入与 4px 轻位移；工作流自己的 portal 通过类名限定，不改变其他插件。
- 自适应宽高使用 WAAPI 直接过渡盒子尺寸，不缩放文字；忽略自身 ResizeObserver 动画帧，快速反向切换从当前绘制尺寸重新定位，同目标通知不延长截止时间。
- 首页及画布响应式按钮保留文字自然宽度供布局测量，文字淡出/淡入，按钮宽度双向过渡，避免模式反复切换。
- 系统“减少动态效果”开启时停止非必要动画；偏好切换、菜单移除和插件卸载会取消动画、监听、观察器及待处理帧。

## 后续：菜单透明度修正

用户反馈卡片操作菜单持续透出底层文字。实测入场结束后菜单 opacity=1，但菜单沿用宿主的半透明材质；本轮在工作流菜单范围内把材质变量改为不透明的主题高层底色，同时设置同色背景并关闭材质模糊。保留边界、阴影、悬停态及 160ms 展开动效。

整包构建、类型检查及 50 方法 schema 检查通过。真实 Web 复核菜单背景为 `rgb(255, 255, 255)`、opacity=1、材质 filter=none；卡片标题不再穿透菜单。[效果截图](evidence/ui-polish-20261017/menu-opaque.jpg) · [前后样式记录](evidence/ui-polish-20261017/menu-opacity.json)。

# 侧栏滚动与展开编辑验收

日期：2026-10-16。

## 原因与修改

运行卡片 `.vdw-data-content` 同时使用 `overflow:auto` 与 `overscroll-behavior:contain`。短卡片没有内部滚动空间时仍阻断滚动链，使滚轮放在卡片上时难以滚动外层侧栏。卡片改为自然传递滚动；外层侧栏仍限制滚动边界，不移动画布和宿主页面。

代码/JSON/模板编辑器移除底部常驻快捷键文字，保留不可见无障碍说明、错误和操作反馈。复制按钮右侧新增展开入口。代码、提示词和运行数据共用 `ExpandedEditorShell`：右侧白色圆角浮层，640px 宽，视口两侧最小留 16px，内部灰底内容填满可用高度；工具条保留复制、格式化（适用时）和收起，无独立标题栏、完成按钮或暗色遮罩。

参考为用户打开的真实 Dify 工作流：其展开提示词为右侧白壳灰底浮层、保留原工具条；本插件按用户要求加宽。仅查看参考，没有编辑、运行或发布 Dify 流程。

## 验证

- 完整构建、类型检查通过；8 个相关测试文件、66 项回归通过，覆盖展开/收起同步、无效 JSON 草稿、只读与禁用、焦点恢复、变量、下拉和侧栏隔离。
- 在真正 DSH Web（5188）验证迭代节点的上次运行：滚轮在卡片内向上后外层 `scrollTop=0`，向下后为 `92`（该面板最大值）；画布 transform 前后相同。
- 输入映射展开后填入无效 JSON，格式化不覆盖原文；Esc 收起后原文和错误仍在，焦点回到展开按钮。已恢复原来的 `{}`，未改变节点执行配置。

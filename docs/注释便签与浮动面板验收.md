# 注释、便签与浮动面板验收

日期：2026-10-15。以 DESIGN 第 9 节为本轮规范，先保存规范再实现。本报告只覆盖本轮变更，完整 Dify 对标仍按 [差异矩阵](Dify全量实现状态.md) 推进。

## 1 本轮实现

- 聊天修改注释采用同一个编辑器：节点数字入口、输入框“N 条注释”入口均可编辑或删除。删除最后一条精确移除对应原生引用，保留正文与其他引用。多条编辑全部保存，发送中拒绝修改，迟到发送回执不清除新版草稿。
- 持久便签支持原位编辑、拖动、调整尺寸、五种柔和颜色、删除和撤销。每次完成操作形成一个撤销步骤。切换编辑对象、失焦、快捷键保存均保留正文；Esc 取消不重复回写。
- 便签可连接一个顶层节点，多个便签可连接同一节点。虚线仅为说明关系，不进入执行图。节点移动时便签跟随；手动移动便签更新相对位置；自动整理重排；删除锚点保留便签并解绑定。复制整个流程映射新节点 ID。
- 浮动节点配置/运行面板靠右，上方避开操作组，底部留白。右下小地图和缩放组向左避让；窄侧栏另留底部操作行。被遮挡节点用 260ms 过渡居中，手动操作可中止，减少动态效果偏好直接定位。
- 三角区域控件改为 28px 高、12px 字号、16px 图标；小地图为 160×100。V/H 切换模式；节点和便签方向键移动，Shift 大步长，长按到松开仅一条撤销。
- 新便签避开现有节点/便签后定位到可视区；适应视图包括便签。SVG 包含便签大小、颜色、说明连接，支持负坐标。

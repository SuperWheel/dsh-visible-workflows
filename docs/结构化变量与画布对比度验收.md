# 结构化变量与画布对比度验收

日期：2026-10-16。设计依据：[DESIGN.md 第 19 节](../DESIGN.md#19-可引用变量与画布可见性2026-10-16)。版本保持 v0.0.1。

## 改动

- 可引用变量按来源分为独立卡片：白色标题栏与字段数、浅灰字段区、变量名与类型、说明、复制引用。沿用“上次运行”的圆角、字体、层次和分隔线；无字段时展示准确空状态。
- 复制仍使用完整稳定引用，失败时显示可选择的原始引用。仅以成功运行的数据补充字段元信息，不将实际结果伪装为字段说明，不改变上下游可用范围。
- 画布专属节点边框、端口及连线适当加深。选中节点的全部输入、输出及分支端口整颗填充业务蓝色；多选同样适用。悬停、键盘焦点与待连接目标保留实心反馈。
- 改动限于插件组件与专属样式，不修改宿主主题或 CLI Worker。

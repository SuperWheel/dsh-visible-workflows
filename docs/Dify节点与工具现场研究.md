# Dify 节点与工具界面研究

记录日期：2026-10-14。研究对象为用户已打开的 Dify Cloud「工作流：文本摘要器」，以及当日官方节点手册和公开源码。现场操作只打开菜单和已有节点面板，没有运行、添加、删除或修改用户的节点。未在现场操作过的节点效果，依据官方文档与源码说明，不标为现场实测。

## 1 现场观察

| 对象 | 观察结果 | 插件对应要求 |
| --- | --- | --- |
| 添加节点 | 左侧工具栏旁弹出约 400px 宽面板；节点、工具、开始、Snippets 四个页签；搜索框；分组列表 | 按类型和搜索添加，显示类型含义；保持 Harness 字体、间距和控件 |
| 节点列表 | AI、问题理解、逻辑、转换、工具分组；节点名称旁有图标，说明文案可读 | 不把不同类型简化成同一个文本框 |
| 工具列表 | 搜索、全部/工具插件/Swagger API/工作流/MCP、排序与分组；提供方可展开操作 | 从真实目录读取；选择具体操作才创建节点 |
| 时间工具 | 展开当前时间、时间戳、时间戳转换、时区转换、星期几计算器 | 内置工具实际执行，不用虚构安装量或市场推荐 |
| 开始页签 | 用户输入、定时触发器、Webhook；已有输入显示已添加；说明用户输入不能与其他触发器组合 | 只能让实际实现的起点可添加，依赖状态说明清楚 |
| Snippets | 当前账户列表为空 | 展示实际可用片段，不虚构用户保存内容 |
| LLM 配置 | 右侧面板；标题、运行/帮助/更多/关闭；设置/上次运行；模型、上下文、SYSTEM/USER、输出、结构化输出、重试和异常处理、下一步 | 类型专属配置；实际模型目录；角色预设仍遵循本项目已确认规则 |
| LLM 卡片 | 标题、模型信息条、提示词摘要、连接端口 | 显示有助理解的运行摘要，不将完整表单塞入卡片 |
| 输入配置 | 输入字段、必填标识、类型与下一步 | 具名字段和输入校验，缺项通过询问框补充 |
| 输出配置 | 具名输出变量及其上游来源与类型 | 保留稳定身份引用和具名输出 |
| 右键菜单 | 运行此步骤、更改节点、拷贝、复制、删除、帮助；底部关于与语义说明 | 已实现操作可用；附加本项目固定和聊天注释功能；不能留下无动作按钮 |

## 2 各类节点的含义与图形差别

| 节点 | 用途 | 配置重点 | 画布表现 |
| --- | --- | --- | --- |
| Agent | 按任务选择并调用允许的工具 | 模型、提示词、角色、工具范围、最大步数 | 模型与工具摘要 |
| LLM | 调用模型生成文本 | 模型、强度、角色、提示词与变量 | 模型条和提示摘要 |
| 知识检索 | 检索指定资料返回有关片段 | 查询、来源、条数及阈值 | 来源和查询摘要 |
| 输出 | 汇集需要返回的结果 | 输出名称、上游值 | 名称与来源 |
| 问题分类器 | 用模型把输入分到指定类别 | 模型、输入、各类标题和描述 | 每类一个独立出口 |
| 条件分支 | 按明确条件选择路径 | IF/ELIF 条件组、AND/OR、ELSE | 各条件与各出口分别显示 |
| 人工介入 | 暂停等待用户输入或决策 | 表单、按钮、等待超时 | 决策出口及超时出口 |
| 迭代 | 对数组每项运行内部流程 | 数组、内部节点、结果变量、并发和失败策略 | 容器及内部节点预览 |
| 循环 | 重复内部流程并保留跨轮状态 | 初值、停止条件、次数上限、内部流程 | 容器、轮次与内部节点 |
| 代码执行 | 自定义数据处理 | 语言、输入、代码、输出定义 | 语言和输入/输出摘要 |
| 模板转换 | 将变量渲染成文本 | 模板、输入变量 | 模板摘要 |
| 变量聚合器 | 统一互斥分支的结果来源 | 分组及候选变量 | 聚合组摘要 |
| 文档提取器 | 从文件提取文本 | 文件来源及格式依赖 | 文件来源摘要 |
| 变量赋值 | 更新可写状态 | 目标、操作、来源 | 赋值动作摘要 |
| 参数提取器 | 从自然语言提取结构化参数 | 模型、文本、参数定义 | 参数名称和类型 |
| HTTP 请求 | 请求外部 API | 方法、地址、头、请求体、超时 | 方法与地址 |
| 列表操作 | 过滤、排序并截取数组 | 来源、条件、排序、数量 | 列表操作摘要 |
| 工具 | 执行选中的具体工具操作 | 操作及其参数 Schema | 提供方、操作名和参数摘要 |

## 3 非同义节点必须区分

- 迭代的每项独立；循环下一轮依赖上一轮状态。不能都实现为重复文本替换。
- 聚合器选择实际执行分支的值，不能当成把所有分支拼接成数组；合法的 `false`、`0` 和空串需要保留。
- 人工介入需要在同一次运行暂停和继续，重复提交不能重复执行后续节点。
- 工具提供方与具体操作不是同一个对象；工具参数、可用性、凭据及权限由实际宿主和工具决定。
- 模型节点、分类器、参数提取和 Agent 虽然都调用模型，但返回约束和路由行为不同。
- 本项目已有工作流独立执行、稳定引用、节点编号、聊天注释和角色预设规则继续适用。

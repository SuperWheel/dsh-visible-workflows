# 画布点位批注验收

日期：2026-10-16。依据 [DESIGN.md 第 17 节](../DESIGN.md#17-画布点位批注2026-10-16-最新修订)，覆盖前轮固定宽编号胶囊及输入左侧序号的规则。

## 本次修订

- 蓝色批注序号保留在画布实际点击位置；评论输入不再重复显示左侧蓝序号。一条批注可引用多个节点，画布只显示一个点位标记。
- 浮层优先向标记右侧展开，空间不足时向左；两侧均不足时选择空间较大的一侧并限制在视口内。浮层与标记边缘间隔 10px，纵向按标记中心及浮层实测高度避边。
- 节点胶囊按编号内容自适应宽度；溢出依据实际胶囊和容器宽度计算。删除叉绝对定位，悬停不改变胶囊宽度；遮罩依据 SVG 图标与文字的实际交叠像素计算。
- 保留节点搜索、引用增删、多条批注切换、错误时保留草稿，以及 Enter 仅提交草稿、Shift+Enter 换行和中文输入法保护。

## 检查结果与待复验项

- 本轮相关 **12 个测试文件、136 项用例全部通过**；构建、类型检查及差异检查通过。
- 最终遮罩按内部 12px SVG 测量，保留透明 20px 点击区。Web 实测 `a-1` 文本与图形交叠 9px，遮罩变量为 9px，渐变过渡 2px；胶囊仍为 39.85px，叉下方无残留文字。[最终渐隐截图](../.cache/annotation-point-evidence/web-hover-final.png)。

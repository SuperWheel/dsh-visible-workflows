# 图编译与端口

> 核对日期：2026-10-16。当前实现审计；返回[总索引](../README.md)。

画布的一层 `NodeGraph` 编译为一个 Graphon 图。运行前先在宿主校验，Python 桥再检查一遍图结构；坐标和卡片样式不会改变执行顺序。

## 编译规则

| 画布对象 | 发送到 Python 的信息 | 生成对象 |
|---|---|---|
| 节点 | 稳定 `id`、`kind` | 自定义 `BridgeNode` |
| 连接线 | `id`、`source`、`target`、可选 `port` | Graphon `Edge` |
| 输入节点 | `kind: input` | `NodeExecutionType.ROOT` |
| 条件、分类、人工节点 | `if`、`classifier`、`human` | `NodeExecutionType.BRANCH` |
| 其他节点 | 原 `kind` | 普通执行节点，工作回调宿主 |
| 坐标、编号、配置、便签 | 不放进 `execute.graph` 的节点定义 | 保留在宿主图/运行快照中 |

节点运行结果 `data` 会返回 Python 桥作为 Graphon 节点输出；但模板、变量查找和后续节点配置解析仍使用宿主作用域。不是让 Graphon 的 `VariablePool` 取代宿主的数据模型。

## 端口规则

- 普通节点只有 `default` 出口，省略 `port` 等同 `default`。
- 旧式条件节点出口是 `true` / `false`；多条件节点出口是 `case.id` / `false`。
- 分类节点出口是配置的类别稳定 ID，不是类别名称。
- 人工节点出口是操作 ID、`default` 或 `timeout`。正常操作还会激活 `default`；超时仅激活 `timeout`。
- Python 桥把宿主返回的 `activePorts` 映射为私有的 `dsh:active` / `dsh:inactive` 句柄，再让 Graphon 传播激活与跳过状态。画布端口身份不因此变化。

这套映射解决了一个分支可同时启用“人工指定操作 + 默认后续”的问题。协议测试里更宽松的自定义端口字符串，并不代表产品表单接受任意字符；宿主身份 schema 仍限制字母、数字、下划线、连字符。

## 合法图与容量

| 约束 | 插件实际限制 |
|---|---|
| 每层入口 | 执行时恰好一个输入节点，且不能有入边 |
| 本层连线 | 不跨容器，不重复，出口必须属于源节点 |
| 循环连线 | 禁止；使用显式循环容器 |
| 可达性 | 执行节点全部可从输入到达 |
| 单层图 | 1～200 节点、最多 1,000 连线 |
| 完整工作流 | 含子图最多 500 节点，最多 5 层子流程嵌套 |
| 便签 | 最多 200 个；便签连接只表示视觉跟随 |

Python 协议还接受最多 2,000 节点/10,000 连线，但产品先经过更严格的宿主限制，不能把协议上限当成画布承诺。`topologicalNodes()` 仅用于校验环，不是实际调度器；真正调度仍由 Graphon 执行。

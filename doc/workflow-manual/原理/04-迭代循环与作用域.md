# 迭代、循环与作用域

> 核对日期：2026-10-16。当前实现审计及本轮真实 Graphon 边界探测；返回[总索引](../README.md)。

迭代和循环的外层控制由宿主运行器实现。内部每一项或每一轮都真实执行一张 Graphon 图，没有启用 Graphon 原生迭代/循环节点或原生容器帧。

## 迭代：数组每项运行一次子图

1. `iterator` 解析为数组，最多 1,000 项；可读取变量或合法 JSON 数组字面量。
2. 为每项建立内部作用域：继承外层已产生的值；提供 `item`、`index`；复制可写变量。
3. 每项调用 `executeGraph(body)`，由 Graphon 调度内部节点。
4. 按 `outputVariable` 取每项输出，按原输入顺序收集，完成先后不改变结果顺序。

空数组直接得到空结果，不启动任何内部图。并发开启时，宿主维护上限为 1～10 的任务池。这个开关控制不同迭代项的内部图并发；每张内部图的 worker 数另由执行策略和该层节点决定，见[分支、合流与并发](03-分支合流与并发.md)。

## 单项失败策略

| 选择 | 实际结果 |
|---|---|
| 终止迭代 `terminate` | 默认；失败立即使容器失败，并取消仍在途的并发项 |
| 留空继续 `null` | 失败项输出 `null`，其余项继续；保留原长度和顺序 |
| 移除失败项 `remove` | 丢弃失败项输出，成功项保持原相对顺序 |

退出循环、人工暂停和用户取消均不会被当作普通项错误转换。并发迭代若含任何嵌套人工节点会明确拒绝，需改用顺序模式，避免多个等待表单争用同一次运行的等待状态。

## 循环：共享变量，逐轮执行

- 先合并外层变量与 `initialVariables`；循环内赋值更新这份共享变量。
- 每轮建立独立节点结果作用域和零起始 `index`，调用内部 `executeGraph(body)`。
- 每轮结束检查 `until`；匹配时退出。最大轮数默认 10、上限 100。
- “退出循环”只有放在循环作用域中才有效。内部 Graphon 暂停事件转换为 `ExitLoop`，穿过嵌套迭代直到最近 loop 捕获；只结束该 loop，外层后续仍可继续。
- `outputVariable` 指定最终读取值；未指定时返回循环变量，以及实际 `iterations`。

此实现是先执行、后检查退出条件；不要当成进入第一轮之前检查的 while 条件。

## 嵌套与恢复

执行记录 ID 包含容器路径、项/轮索引及稳定节点 ID，例如 `container[2]/node-id`，区分“同一个节点在第几轮的执行”。人工恢复时容器重新进入循环，但已成功的子步骤读取缓存，赋值按缓存重新还原到变量，不重复执行之前的工具。

最多 5 层子流程、完整图最多 500 节点；一次运行最多累计 5,000 个节点步骤。后者可能先于大数组、多轮循环的理论乘积触发。

## 修复前历史：迭代失败策略吞掉外层退出信号

初次审计以真实 Graphon 0.7.0 执行“循环 → 迭代 → 退出循环”，循环上限 3 轮、迭代数组为 `[1]`。只切换迭代失败策略，结果如下：

| 迭代失败策略 | 修复前外层轮数 | 历史结论 |
|---|---:|---|
| `terminate` | 1 | `ExitLoop` 向外传播，外层循环退出 |
| `null` | 3 | `ExitLoop` 被迭代当作项失败处理，外层继续到上限 |
| `remove` | 3 | 同样吞掉控制信号，外层继续到上限 |

这是宿主迭代 catch 分支未区分 `ExitLoop` 与普通项错误造成的历史缺陷，不是 Graphon 不支持暂停。原始记录保持不改，以便对照修复前后的契约。

探测记录见[边界与存量流程证据](../验证/边界与存量流程证据.json)中的 `exitLoopInsideIteration_*`；复现构造见[边界探测脚本](../../../scripts/audit-graphon-boundaries.ts)。

## 当前修复与边界

三种迭代失败策略均重新抛出 `ExitLoop`，不记作普通项错误。并发任务池收到该信号后停止派发新项，取消未完成同伴并等待清理；同伴中止错误不会取代退出信号。最近 loop 接收信号后结束，其外层 loop 可以继续。已完成外部副作用不回滚。

[新增真实 Graphon 回归](../../../tests/nested-loop-control.test.ts)包含顺序/并发×三种策略、未完成同伴取消、最近 loop、人工暂停与进程重开、用户取消。代码已修复；本页不预写本轮最终全套测试数量或 Web/桌面验收结论，详见[修复记录](../验证/问题/01-迭代吞掉退出循环.md)。

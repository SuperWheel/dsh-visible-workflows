# 变量与稳定身份

> 核对日期：2026-10-16。当前实现审计及本轮真实 Graphon 边界探测；返回[总索引](../README.md)。

节点显示编号会随结构调整，变量引用使用稳定节点 ID。变量解析、模板渲染和类型校验由宿主实现，并未迁移到 Graphon 的原生变量池表达式系统。

## 可读的数据根

| 表达式 | 含义 |
|---|---|
| `input.text` | 当前作用域输入字段 |
| `稳定节点ID.text` | 当前节点依赖祖先中已产生的结果字段 |
| `稳定节点ID` | 可见依赖祖先的结果对象 |
| `vars.count` | 容器作用域可写变量 |
| `item` / `item.field` | 当前迭代项，仅迭代中可用 |
| `index` | 当前项或轮的零起始序号，仅容器内部可用 |

显示的 `a-1`、`b-2` 是定位标签；不要把它们当作会长期不变的模板键。实际稳定 ID 也可能恰好采用相似文本，但约束来自 `node.id`，不是 `node.number`。

## 类型如何保留

- 映射值恰好是 `{{引用}}` 时，保留原 JSON 类型并复制该值，例如数组仍是数组。
- 引用混在普通文字中时，非字符串会 JSON 序列化；结果是文本。
- 输入按字段类型解析数字、布尔、JSON、文件等；数值/选项不合法时拒绝。
- 模型或代码结构化输出按声明的字段是否存在及类型校验，不是只看 JSON 能否解析。
- 禁止 `__proto__`、`prototype`、`constructor` 等危险路径。

## 模板能力边界

模板转换走 TypeScript 的 `renderDataTemplate()`，支持受限 Jinja 兼容语法：变量、注释、for/if/elif/else、有限比较以及 `default`、`upper`、`lower`、`trim`、`length`、`join`、`first`、`last`、`tojson`、`replace`、`sort` 过滤器。超过范围会明确报错。

它不调用 Python Jinja2，也不支持任意函数调用、导入或完整 Jinja 标签。预构建环境含 Jinja2 包，只能证明依赖存在，不能写成“模板节点已支持完整 Jinja2”。普通输出、提示词等则用较简单的 `{{变量}}` 插值，不等同模板节点的 for/if 语法。

本轮真实执行包含 `{% macro greet() %}` 的模板，运行失败并返回“当前模板不支持标签 macro greet()”。这是对上述语法边界的实际复现，不是仅根据安装依赖推断。

## 当前作用域与依赖边界

- 每次顶层运行创建新的值表，不读取历史运行恰好存在的结果。稳定 ID 引用也必须属于当前节点的直接/传递祖先，不能读取仅仅先完成的兄弟节点。
- 进入子容器前可见的外层祖先会继承；容器自己尚未完成的结果、其他容器内部节点不可读取。子层结果通过容器输出对外暴露。
- `vars` 按依赖隔离：节点读取进入本图时的变量快照及其上游赋值节点结果。无依赖兄弟赋值即使已经完成也不会覆盖该节点读到的值，裸 `{{vars}}` 同样只含可见字段。
- 顺序迭代各项复制变量；循环保留轮间状态。循环初始变量、迭代 `item`、容器 `index`、模板具名输入和局部 for 变量、同一赋值节点中已执行语句有各自局部规则。
- 可执行预检通过 `referenceScopeIssues` 检查实际会解析的配置字段，运行时再通过 `assertReferenceAllowed` 守卫。不会把代码正文、说明或普通字面量误当成模板引用；未完整草稿仍可保存。
- 全图未知或合法上游尚未产生的缺失值保留原运行时行为：模板 `default`、可选聚合与既有失败策略仍可兜底，必填读取仍可能失败。已知越界节点/变量始终拒绝，不能用 `default` 或 `is defined` 隐藏越依赖访问。

## 修复前历史证据

初次审计构造 `start → a` 与 `start → b → out`，没有 `a → b` 依赖边；`b` 手写 `{{a.text}}` 仍成功输出 `from-a`。当时同层值表与预检缺少祖先约束，该成功不能作为合法数据依赖。当前已补预检、运行守卫和变量隔离，见[问题修复记录](../验证/问题/02-兄弟支路越依赖引用.md)。

该历史复现与完整 Jinja2 边界探测均使用真实 Graphon、未调用外部模型；保留的[边界与存量流程证据](../验证/边界与存量流程证据.json)包含 `siblingReferenceWithoutDependency` / `fullJinjaMacro`，构造见[边界探测脚本](../../../scripts/audit-graphon-boundaries.ts)。完整 Jinja2 仍未接通，不因引用修复改变。

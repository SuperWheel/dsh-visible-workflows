# 分支、合流与并发

> 核对日期：2026-10-21。当前实现审计；返回[总索引](../README.md)。

Graphon 负责判断哪个节点已经满足依赖、哪些边被激活、哪些路径应跳过。每层图默认使用 3 个 worker；多个就绪分支可以并行，实际并发还取决于图结构、节点种类和模型并发上限。

## 四种常见结构

| 结构 | 实际行为 |
|---|---|
| 普通节点分出两条边 | 两条都激活，按 Graphon 就绪调度执行；有可用 worker 时可以并行 |
| 条件 / 分类 | 宿主选定出口，Graphon 跳过其他路径 |
| 两条有效路径汇合 | 等待相关前置路径完成后才运行汇合节点 |
| 条件路径汇合 | 被跳过路径传播跳过状态，不会让有效路径的汇合永久等待 |

输出节点声明该节点的结果，不会提前停止其他已激活路径。顶层输出写入 `run.outputs[outputName]`；第二个实际激活的同名根输出会在渲染与写入前失败，保留首值。互斥分支未同时激活时允许共享输出名，子层输出不写根结果。不能依赖兄弟分支调度顺序表达结果优先级。

初次真实 Graphon 探测曾出现两个输出成功、结果只保留 `second`；这是修复前历史。[输出冲突回归](../../../tests/output-collision.test.ts)新增检查冲突、互斥、人工恢复与子层隔离；详情及原始证据见[运行记录与版本](08-运行记录与版本.md#同名输出保留什么)、[问题修复记录](../验证/问题/03-同名输出覆盖.md)。

## 条件与分类的决策

- 多条件 IF 从上到下取第一个匹配 case；case 内按 AND / OR 判定；全不匹配使用 `false`。
- 条件比较在 TypeScript 内处理数字、布尔、字符串、数组与空值；不是交给 LLM 推断。
- 分类由模型返回已定义的 `class_id`。未知类别或无效 JSON 失败，不随意选第一个类别。
- 人工操作正常激活所选操作与默认路径；超时不激活默认路径。

## “汇合”与“变量聚合器”不是同一个功能

Graphon 的汇合解决“什么时候可以运行”。宿主变量聚合器解决“从互斥候选变量中取哪一个值”。每组必须恰好有一个已存在的候选值；合法 `false`、`0`、空串不会被当作缺失。两个都存在或一个都不存在都会报错。

因此，两个普通有效分支的数组汇总不能直接用变量聚合器代替，应在下游用代码或模板明确组合。

## 当前并发边界

| 层级 | 当前行为 |
|---|---|
| 同一个 Graphon 图 | `min_workers` 与 `max_workers` 使用相同配置；默认 3，按 `executionPolicy.maxConcurrentAgents` 取 1～8；该层有 `human` 或 `assigner` 时为 1 |
| 并发迭代 | 宿主同时提交多个内部图；并发上限 1～10，默认 3 |
| 独立顶层运行 | 宿主最多同时 4 个正在执行的工作流；同一工作流不能有第二个未结束运行 |
| 模型调用 | Runtime 与规划服务共用 `ModelAdmission`：插件内全局上限 8、工作区上限 4；每个业务运行另受自己的执行策略限制 |
| Python 桥 | 可同时管理最多 128 个活动图请求；这不是用户可直接调到的并发配置 |

运行器按每个节点的合法依赖重建可见变量，不让兄弟分支的到达先后改变引用结果；人工等待和赋值所在层仍串行。规划子 Agent 的并发另有全局 2、工作区 1 的上限，详见[规划资源保护与并发](../规划引擎/07-资源保护与并发.md)。图 worker、迭代任务池和模型容量是三类限制，不能将它们相乘当作允许的模型调用数。

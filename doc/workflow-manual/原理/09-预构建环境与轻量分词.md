# 预构建环境与轻量分词

> 核对日期：2026-10-21。依据随仓库资源与清单；返回[总索引](../README.md)。

用户不需要手动安装 Python。插件随包提供私有解释器和受控依赖，首次执行时校验、解压并自动准备；模型与文档解析仍复用 DSH 或已授权的工具/MCP。

## 环境里有什么

| 项目 | 当前锁定内容 |
|---|---|
| Python | CPython 3.12.15 |
| 图引擎 | Graphon 0.7.0，使用原版 `GraphEngine` |
| Python 包 | 清单规定 28 项；含 tiktoken/Jinja2/Pydantic 等核心依赖 |
| 分词词表 | 离线 `cl100k_base`，固定 SHA-256 |
| 不打包的重型能力 | Transformers、Unstructured、OCR/Office 解析栈等 |
| 当前默认交付平台 | macOS ARM64 |

这是一套受控的私有运行环境，不是重新发布了一个独立的 Graphon 精简 wheel。Graphon 上游完整依赖元数据可能仍声明其他可选能力所需库，不能用“完整上游 pip check 无缺失”来描述此分发。

## 第一次执行如何准备

1. 按平台找随包资源，不查询系统 Python，也不修改 PATH。
2. 校验平台 manifest 与压缩包 SHA-256。
3. 在私有临时目录解压，仅接受安全的普通文件路径，拒绝链接、越界路径和超额展开。
4. 校验解释器、依赖清单、词表的摘要，进行禁网络的版本/导入/分词探测。
5. 写就绪标记并原子移动目录；并发调用共享安装锁。
6. 后续复用版本摘要命名的目录，启动 Python 时使用 `-I -B -u` 及清理后的环境变量。

初始化失败不会静默切换到系统 Python，也不会在线 pip/uv 补包。此环境本身不是代码沙箱；代码节点仍需宿主完整文件沙箱授权与隔离。

## 体积按哪一个数理解

macOS ARM64 资源清单记录：压缩包 **31,136,038 B（约 31.14 MB）**；展开普通文件 **86,615,433 B（约 86.62 MB）**，2,626 个文件。这是清单中的构建测量值，不是本页重新测出的磁盘分配占用。

随包压缩资源会保留，首次运行后还存在展开环境，因此不能只用 31 MB 或 86 MB 之一代表总磁盘开销。用户记录、附件和宿主本身另计。

Windows x64 有构建配置和静态验证方案，历史产物声明 `static-only / executed: false`；默认 macOS 插件资源不能因此称为 Windows 已适配。Linux 与 Intel Mac 没有当前受支持的资源映射。跨平台结论需分别实机验收。

## 分词是什么、什么时候调用

- LLM、分类、参数提取调用模型前，宿主发送 `count_tokens`；Agent/文档 Agent 的模型后端包装也走同一估算入口。
- 计数输入为本次 system 与 prompt 文本，不代表所有工具轮次、附件和提供方协议开销的精确 Token 用量。
- Python 桥用 tiktoken `cl100k_base`；词表缺失或摘要不符就明确报错，不联网下载，不退回 Transformers。
- 结果明确标记 `estimated: true`。DSH 中采用其他分词器的模型仍只是近似估算；用于输入规模与性能估算，不能据此保证上下文一定不超限，也不能替代提供方实际 Token 回执。

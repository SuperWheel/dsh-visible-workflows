## 阅读状态约定

- **真实引擎通过**：确实启动内置 Python/Graphon，模型可能由受控测试数据代替；以每项证据说明为准。
- **实际适配器通过**：QuickJS、本地文件、内置工具或回环 HTTP 确实执行；不扩张成任意 MCP/模型服务已可用。
- **静态确认**：追踪当前源码和配置契约；不等于该完整界面路径已在本轮实机操作。
- **缺陷已复现**：在隔离数据中观察到实际问题；本次记录，不偷偷改产品或用户流程。
- **已修复**：另有修复后的源码、回归与验收记录；保留初次复现的历史证据。
- **未接通/待实测**：单列限制和依赖，不用 Graphon 上游支持替代插件实现。

本轮原始工作流库均只读。3 个满足条件的存量流程在临时存储副本中执行通过，其余 6 个列出未执行原因；不发送聊天、不调用真实模型、不调用外网 MCP。详见[存量流程核验](验证/02-存量流程核验.md)。

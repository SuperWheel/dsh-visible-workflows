## 1. 本轮确定的行为

| 部分 | 本轮实现 | 保留边界 |
| --- | --- | --- |
| 环境变量 | 编辑器显式提供字符型、数字型、密钥；新增默认字符型，可直接填值；密钥能力检查折叠显示 | 字符型和数字型可被 Agent 读取，只有 Secret 进入原生凭据管理；不新增网页密钥输入 |
| 保存 | 标题后保存、另存为图标；保存期间旋转，结束提示已保存；快捷键保存/另存为 | 保存失败保留当前修改；缺少资源的画布仍可保存 |
| 保存模式 | 原生“设置 → 工作流”提供手动/自动，默认自动每 5 分钟，1—1440 分钟可设 | 这是本机客户端偏好，不随 JSON 分享；切换流程的保存保护保留 |
| 配置检查 | 普通画布编辑只标记变化，保存时检查；检查正常不弹警告 | 首次打开/导入、主动重新检查和执行前继续核对资源，不信任旧结果 |
| 执行 | 执行按钮可点；先保存最新定义再检查；存在问题弹框引导 | 不创建缺少必要配置的运行，不绕过 Host 最终检查 |
| 另存为 | 当前画布生成新流程，保留位置、便签、批注、普通变量 | 新身份不会继承 Secret 原值、持久授权、本机会话或运行历史 |
| 高级设置 | 左工具栏图标打开环境变量、全局变量、执行预算三个标签 | 复用节点目录样式；全局变量就是原只读 `sys`，不增加可伪造的系统值 |
| 导出 | 单一导出图标，原生菜单向右出现 JSON / SVG；导入保留独立入口 | JSON 项保留原完整导出面板及 ZIP；SVG 仍仅供展示 |
| 子 Agent | 卡片内可输入名称、下拉选择、新建；独立 ID、编号和名称；角色预设随身份绑定 | 身份属于当前工作流和主对话，每次执行仍是独立原生任务 |
| 提示词 | 用户确认方案 B：`subAgents[].prompt` 保存共享角色，`config.prompt` 保存节点任务 | 角色预设复制为快照，显式更新才同步；Secret 不得进入提示词 |
| 对话预算 | 新建前原生问答；选择“是”继续填额度，“否”不加额外预算；结果绑定流程 | Agent 不能代答；后续不重复问；宿主权限和执行安全上限继续生效 |

画布结构、稳定节点引用、批注、便签、容器内部图、JSON/ZIP 迁移及原生 Secret 组件沿用现有实现，本轮不更换执行环境。

## 2. 当前数据结构与交换

新增字段见 [JSON 第 5.2、8.1 节](../原理/10-JSON字段与导入导出.md)：

- `Workflow.subAgents[]`：身份、编号、名称、角色提示词；本地可记录主对话及预设来源。
- `NodeConfig.subagentId`：引用工作流内定义，不能当作原生任务 ID。
- `Workflow.budgetDecision`：预算选择及首次完成时间；额度在 `executionPolicy`。
- `NodeExecution.subagentDefinitionId`：运行记录中的定义身份，与原有原生任务 `subagentId` 分开。

导出清除子 Agent 的 `sessionId`、本地 `rolePresetId` 和 `rolePresetRevision`，完整保存角色文本。导入与另存为重建定义 ID 和节点引用，保留编号、名称、文本。Secret 始终只迁移声明；工作流 JSON 不能夹带认证、授权或凭据载体。

当前仅支持 `subAgents[]` 与 Agent 节点 `config.subagentId`；节点旧 `rolePresetId` 直接拒绝，不转换、不创建替代身份。未填写子 Agent 身份仍可保存为待配置。其他模型节点继续使用合法的预设引用字段。此前验收证据保留原样，当前唯一格式及本轮检查见[规划引擎执行方案](../../../docs/Agent辅助生成工作流后端引擎执行方案.md)。

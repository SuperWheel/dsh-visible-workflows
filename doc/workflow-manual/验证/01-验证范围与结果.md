# 本轮验证范围与结果

[返回总索引](../README.md)。执行日期：2026-10-16；macOS Apple Silicon，内置 Python 3.12.15、Graphon 0.7.0。插件仍为 v0.0.1。本轮新增手册、验证脚本和集成测试，**没有修改产品运行逻辑、替换桌面安装包或修复原流程**。

## 实际运行的验证

| 证据 | 结果 | 能证明什么 |
| --- | --- | --- |
| 全量 Vitest | **43 个文件、388 项通过，0 失败、0 跳过** | 现有客户端组件/状态、Host、SDK契约、适配器及实际Graphon执行测试；不是388条用户实机流程 |
| Python 桥接协议 | **14 项通过，无跳过** | 实际Python子进程：拓扑/汇合、任意分支端口、人工默认/超时、暂停/退出、失败、取消、子图、无效图和离线分词 |
| 新增20类节点集成链 | **20/20 类均有成功执行记录**，计入上述388项中的1项 | 同一条实际Graphon链串联所有kind，暂停后恢复；具体替身边界见下表 |
| 存量流程核验 | **9/9结构读取，3个隔离副本成功** | 无外部依赖且图可执行的副本；原库哈希未改变 |
| 边界探测 | **6组真实引擎观察** | 兄弟引用、同名输出、Jinja macro，以及3种嵌套退出策略；发现问题不等于验收通过 |

首次全量运行有1项因沙箱禁止本地HTTP监听而报 `listen EPERM`。在仅允许本地测试服务器的环境完成最终全量重跑，上表使用最终结果，没有把环境失败隐藏成首次全过。

## 新增集成链的真实与模拟边界

构造见[graphon-capability-audit.test.ts](../../../tests/graphon-capability-audit.test.ts)。Graphon进程没有被mock。

| 部分 | 本轮具体方式 |
| --- | --- |
| input/template/if/output/list/assigner/aggregator | 实际运行器逻辑和真实Graphon分支/合流 |
| iteration/loop/exit_loop | 实际宿主容器，每项/轮再次进Graphon；并发迭代2路、循环第2轮退出 |
| human | 实际waiting→answer→success，成功步骤时间和模型请求数在恢复后保持不变 |
| code | 实际QuickJS执行JavaScript、返回数组 |
| document | 实际临时UTF-8文件，通过生产本地解析适配器 |
| knowledge | 实际临时文件关键词检索；不证明完整排名或向量检索 |
| http | 实际回环HTTP服务器、Node fetch和JSON响应，不访问公网 |
| tool / Agent工具 | 实际内置JSON工具；宿主/MCP工具由其他契约测试使用替身验证 |
| llm/classifier/extractor/Agent模型决策 | **受控模型响应**；校验真实路由、数据和端口处理，不调用用户的收费模型 |
| Python用户代码 | 未执行正常用户代码；仅覆盖语法拒绝、内置解释器准备及full sandbox准入契约 |

模型默认值、提供方目录、DSH流完成/断流和权限传递另有SDK契约测试。不能据这些结果宣称用户当前模型/MCP连通性、复杂文档准确性或Windows平台运行均已通过。

## 界面组件的验证方式

22篇[交互笔记](../交互/README.md)逐项追踪按钮回调、状态和边界。全量测试覆盖目录、表单相关编辑器、选区、引用、批注、便签、导航隔离、缩略图、裁剪、端口、布局、数据卡片与顶部三级响应等。

**本轮没有新增全套Web/桌面手工点击复验。** 主页完整CRUD、设置预设CRUD、询问弹层的完整可用性、浏览器下载等路径没有因为“静态读过源码”就自动标为实机通过。此前实机证据仍在[历史验收](../../../docs/浮动导航与三级按钮验收.md)，仅支持其明确的范围。

- [边界和存量流程JSON](边界与存量流程证据.json)：每份库哈希、未执行原因、副本执行状态及6组真实观察。
- [存量流程逐项结论](02-存量流程核验.md)、[能力与缺口](03-能力与缺口矩阵.md)。

从仓库根目录运行：

```sh
node node_modules/vitest/vitest.mjs run
npm run typecheck
node --import tsx scripts/audit-graphon-boundaries.ts
node scripts/verify-workflow-manual.mjs
```

全量测试含回环HTTP服务器，需要允许本地监听。边界脚本默认只运行隔离探测；增加 `--library /路径/library.json` 才会只读检查该库并对安全流程执行临时副本，不向原库写入。

Python协议复跑使用独立pytest测试环境，并设置 `GRAPHON_BRIDGE_PYTHON` 为已校验运行时的绝对Python路径、`TIKTOKEN_CACHE_DIR` 为其词表目录，再运行 `python -m pytest tests/graphon-python/test_bridge.py -q`。不要把pytest装进面向用户的精简运行时。

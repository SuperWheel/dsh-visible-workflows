## 当前端口与保边契约

- `nodePorts(human)` 保留用户行动顺序，随后提供稳定端口 `default`（「常规继续」）、`timeout`（「超时」）；未配置行动时保留原 `continue` 回退。旧配置中显式使用保留端口 ID 时不重复生成。
- 「常规继续」表示任何正常人工行动后都可激活的公共路径，与所选行动出口一起运行；超时仍只走 timeout，不走 default。
- 画布可直接连接 default。修改名称/配置时，合法显式 `port: default` 及省略 port 的默认边都保留；删除某个行动仅移除该行动对应边，不误删 default。
- 分支行数、节点高度、出口坐标及连线定位继续共同使用 `nodePorts`；新增默认行位于行动与超时之间，没有改动原行动的 ID 或顺序。

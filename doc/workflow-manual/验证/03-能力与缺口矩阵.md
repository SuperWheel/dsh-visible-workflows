# Graphon适配能力与未完成项

[返回总索引](../README.md)。依据2026-10-16当前源码与[本轮测试](01-验证范围与结果.md)。这里的“可实现”和“本插件已接通”分别列出。

## 已接通的责任分工

| 能力 | 当前实现者 | 实际验证与边界 |
| --- | --- | --- |
| DAG就绪、分支激活/跳过、汇合 | Graphon GraphEngine | 真实引擎协议及集成通过；当前每图1 worker |
| 20种节点分派 | Graphon自定义BridgeNode→TS回调 | [20类全链路](../../../tests/graphon-capability-audit.test.ts)成功；非20种Dify原生节点 |
| 具体条件/列表/模板/赋值/聚合/输出 | 插件运行器 | 实际执行；[节点页](../节点/README.md)列精确语义和限制 |
| 循环、迭代、并发任务池 | 宿主管理容器，内部图用Graphon | 常规测试及新增嵌套退出回归覆盖；退出控制信号不按普通项错误处理 |
| 模型、Agent、分类/参数提取 | DSH模型路由及插件校验 | 默认值/权限/流协议及受控模型响应通过；未调用用户真实模型 |
| JS代码、轻量文档、本地检索、内置工具、HTTP | 插件生产适配器 | 实际QuickJS/临时文件/内置工具/回环HTTP通过 |
| MCP、原生工具、复杂解析服务 | DSH与用户选定服务 | 路由、权限、来源绑定和失败拒绝有测试；外部服务本轮未调用 |
| 用户Python代码 | 预构建解释器＋宿主完整沙箱 | gate和拒绝契约有测试；正常代码及Windows实测未完成 |
| 人工等待与持久恢复 | 宿主快照＋Graphon暂停 | 实际waiting/answer及缓存恢复通过；不是Graphon原生帧持久化 |
| 画布、菜单、按钮、注释、便签、编辑器 | 插件客户端及DSH原生组件 | 静态全目录审计及组件测试；Graphon不生成这些界面 |

## 明确未接通或只有轻量替代

| 目标 | 当前状态 |
| --- | --- |
| 普通DAG分支并行 | 本桥固定单worker；并发迭代是多张子图，不等于普通分支并行 |
| 每节点重试/错误出口/默认值 | 未有通用配置及执行状态机；迭代三种失败策略不属于重试 |
| Agent最多两轮修复、运行中派生版本、采纳原流程 | 目标讨论尚未实现；running/waiting当前禁止保存原图 |
| 完整Jinja2 | 当前模板走TS子集；macro已实测失败，打包含Jinja2不改变此事实 |
| 向量知识库、重排器、混合召回 | 当前是本地关键词分块；部分配置/有效上限不一致需整合 |
| 通用PDF/Office/OCR解析栈 | 已明确委托选定DSH工具/MCP或受限Agent；不是内置完整解析器 |
| 定时触发/Webhook订阅、Snippets库 | 目录提示/空状态，不是可运行触发服务或片段管理 |
| 发布部署、历史版本浏览/差异回滚 | 未接通；SVG仅导出视图 |
| Dify DSL全量导入导出、插件市场安装、Chatflow会话语义、协作 | 未实现完整兼容；不能从Graphon的上游模块推定插件已经具备 |
| 全平台Python用户代码与真实服务质量 | 仍需具体平台、沙箱、模型、MCP现场验收 |

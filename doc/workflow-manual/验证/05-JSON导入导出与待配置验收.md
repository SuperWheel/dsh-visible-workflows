## 1. 本轮交付

| 部分 | 当前行为 |
| --- | --- |
| 缺少资源或配置 | 格式有效即可导入原画布；保留待填写字段，不建立独立草稿区 |
| 画布提示 | 节点标题后显示红色感叹号三角；右侧列出待处理项，可进入节点、环境变量或子流程配置 |
| 保存与执行 | 可以保存未完成流程；执行按钮可点击，缺项时弹窗引导处理并阻止本次启动；Host 在开始、恢复和 Agent 工具入口再次检查 |
| JSON 往返 | 仅支持当前 v2；保留全部 20 类节点、容器图、分支出口、精确坐标、便签、视口与普通批注；重建 ID 及关联 |
| 依赖迁移 | 可用独立子工作流和角色随包保存；未找到的资源保留引用；导入不继承本机连接和授权 |
| 资料迁移 | JSON 保留槽位，ZIP 可附带固定资料；校验摘要、体积、入口与目标字段，导入失败清理新建资料目录 |
| 变量 | 普通值可选导出；Secret 只导出声明，系统变量由目标 Harness 生成 |

结构损坏、未知节点类型、越界连线、错误引用和不安全字段仍会拒绝导入。这些属于无法解释的文件，不属于可在画布里补齐的缺失值。

## 4. 明确边界

- 模型、MCP、工具和原生子 Agent 的全部组合不在本轮实机验证范围；本轮不以模拟回执证明其真实连接成功。
- Secret 当前继续遵守受保护代理的状态检查与拒绝规则；本轮未录入、读取、导出或使用真实密钥，不宣称其原生签名和跨平台隔离已经交付。
- 固定资料需要可读取；尚待上游生成的文件可随 JSON 定义迁移，当前 ZIP 导出会提示改用 JSON。输出产物和运行时上传文件不作为现成附件随包携带。
- 导入导出迁移的是流程定义，不恢复运行日志、聊天回执、授权或某次执行快照。
- Windows 桌面端未在本轮实机验收。

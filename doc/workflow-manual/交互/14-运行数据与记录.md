# 运行数据与记录

[返回总索引](../README.md) · [交互索引](./README.md)

核验口径：2026-10-16 对当前源码作静态核对；相关自动测试已在本轮统一运行，结果见[验证报告](../验证/01-验证范围与结果.md)。本轮没有新增 Web/桌面全套手工复验。

## 入口与状态

- 左下「运行记录」打开详情；下拉选择本流程已有记录，节点列表可展开单次执行，循环/迭代项带项次。
- 节点列表按流程连线顺序排列（2026-10-26 起），不按记录创建先后；容器内的步骤和迭代项排在所属容器之后，并保持实际执行次序。
- 节点配置「上次运行」展示当前所选 run 中该节点最后一次执行，并非重新发起运行。
- 输入、输出、结构化输出使用 DataViewer；结构化数据可切字段/JSON、展开、复制。

## 操作步骤

1. 打开运行记录，选一条记录，查看中文状态、耗时及存在的模型/强度信息。
2. 展开节点，查看真实输入、输出和错误；对象/数组默认折叠，按需显示更多。
3. 复制得到完整原始内容，而非当前可见截断部分；需要长文本阅读可展开右侧大面板。

## 调用链与边界

`WorkflowApp.RunPanel / NodePanel → ExecutionDetails/ExecutionSummary → DataViewer`。数据来自 `WorkflowRun.executions/outputs`，不根据节点名称编造。大数组分批 40 项，长 JSON 初始有限显示；超出安全整数精度的 JSON 字符串保留原始 JSON 查看，避免字段视图误舍入。

渲染属于客户端；运行数据由 DSH 和执行桥接回传。轻量 token estimate 明确是估算，不是提供商账单。没有记录导出、全局日志查询或发布历史回放入口。

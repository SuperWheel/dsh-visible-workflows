# 平移缩放与视口裁剪

[返回总索引](../README.md) · [交互索引](./README.md)

核验口径：2026-10-16 对当前源码作静态核对；相关自动测试已在本轮统一运行，结果见[验证报告](../验证/01-验证范围与结果.md)。本轮没有新增 Web/桌面全套手工复验。

## 入口与状态

- 左侧「指针 / 手模式」，快捷键 V/H；手模式拖动画布，普通滚轮平移，Control/Command+滚轮围绕指针缩放。
- 右下减号、加号和「适应画布」控制 20%–200% 缩放及居中。
- 配置面板遮住节点时视口平滑移动，使其进入剩余可见区域；开启减少动态效果时直接定位。

## 操作步骤

1. 使用手模式拖动或滚轮平移，使用缩放控件调整可见范围。
2. 选择节点打开配置，必要时自动避让；收回面板不会重新执行节点。
3. 切换原生全窗前捕获最新视口，返回时沿用同一个编辑 Store。

## 调用链与边界

`useFrameState` 合并高频输入到逐帧 React 提交；图变更后构建 `createViewportIndex`，`cullViewport` 仅挂载视口及 200px 屏幕缓冲内节点与曲线。曲线使用包含内部极值的包围盒，因此两端均离屏但穿过屏幕的边仍可见；键盘焦点节点保留挂载。

裁剪只减少 DOM，不删除离屏图数据，也不限制 Graphon 执行范围。当前每次视口筛选仍遍历已有索引，不等于空间树索引或无限图规模保证；本次没有新增性能实机测量。

## 入口与状态

- CodeEditor 支持语言栏、行号、高亮、复制、JSON 格式化和右侧展开编辑；PromptEditor 支持 SYSTEM/USER 标签、字符数、说明、复制与同款展开面板。
- 展开与小编辑器共享同一受控值，收起保留修改；运行禁用/只读状态保持一致。
- JSON 编辑器格式未完成时保留本地草稿、显示错误，不覆盖上次有效对象。

## 操作步骤

1. 在代码/JSON 或提示词区编辑；需要更大空间时点击复制旁的展开按钮。
2. JSON 可手动格式化；格式无效时原文保持不变。代码 Tab/Shift+Tab 缩进，小编辑器 Esc 后 Tab 可移出焦点。
3. 展开编辑器用收起或 Esc 关闭；复制始终使用完整原文。

## 调用链与边界

`SpecificConfig/JsonEditor → CodeEditor`；`PromptEditor → ExpandedEditorShell`。高亮用有长度/Token 边界的自建 tokenizer，不通过 HTML 注入；超过 60,000 字符暂停高亮，文本仍保留。

这些编辑器只编辑和保存字符串/JSON，不在输入时执行代码。真实 JS/Python 执行由 DSH 适配器负责，Graphon 不提供浏览器代码编辑器；原生 textarea 负责输入法、选区和普通文本撤销。提示词计数是 Unicode 字符数，只作编辑长度提示；实际 Token 用量依据模型回执作性能计量。

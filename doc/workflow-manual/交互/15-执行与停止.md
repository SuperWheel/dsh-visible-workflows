# 执行与停止

[返回总索引](../README.md) · [交互索引](./README.md)

核验口径：2026-10-16 对当前源码作静态核对；相关自动测试已在本轮统一运行，结果见[验证报告](../验证/01-验证范围与结果.md)。本轮没有新增 Web/桌面全套手工复验。

## 入口与状态

- 右上「执行」先保存并检查最新流程，运行中/等待中切为「停止」；缺失配置不预先禁用执行，点击后弹框提示先处理清单。保存失败不创建运行，操作提交期间防止重复提交。
- 执行无需主聊天 Agent；节点内部仍可包含模型或 Agent 节点。
- 启动后打开运行记录；当前流程存在 running/waiting 时原图编辑禁用，避免运行定义漂移。

## 操作步骤

1. 点击执行，自动保存当前修改；保存图标在写入及检查期间旋转。缺失配置时弹出处理指引，流程仍已可保存。
2. 信息足够时直接运行，缺少输入或人工节点暂停时出现询问框。
3. 点击停止取消当前活跃运行，等待宿主返回取消结果；历史运行仍可查看。

## 调用链与边界

2026-10-17 更新链路：`store.execute → save → flush → inspectReadiness → api.start(workflowId,inputs,sessionId)`；保存及检查结果须对应当前图和会话，Host 启动前仍有最终检查。`poll` 每约 700ms 请求状态；`store.cancel → api.cancel(active.id)`，请求序号阻止旧 running 结果复活已取消状态。本轮实机状态见[迭代记录](../验证/11-保存高级设置与子Agent定义迭代.md)。

当前 Graphon 桥接只负责依赖就绪、边激活、分支跳过与汇合，节点工作回调 DSH。循环、迭代、工具和模型不等于 Graphon 内置节点；详情见桥接协议。按钮接通不代表当前平台预构建环境、凭据和每项节点配置已实机验收。

独立执行不要求主聊天 Agent 为每一步推理，但使用宿主原生工具的流程仍需要准确会话权限。宿主未初始化相应对话上下文时，当前入口会明确要求先在该对话发送消息；这不是无需任何宿主上下文的独立运行服务。

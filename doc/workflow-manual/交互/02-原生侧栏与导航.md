# 原生侧栏与导航

[返回总索引](../README.md) · [交互索引](./README.md)

核验口径：2026-10-16 对当前源码作静态核对；相关自动测试已在本轮统一运行，结果见[验证报告](../验证/01-验证范围与结果.md)。本轮没有新增 Web/桌面全套手工复验。

## 入口与状态

- 左侧「工作流」、对话头部工作流按钮和原生引用均进入 `visible-workflows` 右侧标签。
- 画布返回箭头回工作流主页；子流程面包屑返回父层。全窗/收回使用 DSH 原生侧栏控制，插件不复制一套窗口布局。
- Agent 生成完成先显示「工作流已就绪」通知，用户点击后才查看；不自动抢走另一对话的画布。

## 操作步骤

1. 从当前对话打开工作流；没有当前会话时由 DSH 新会话流程提供准确目标。
2. 使用原生侧栏全窗按钮切换展示，继续使用同一个编辑 Store。
3. 对话改变后再打开，对应会话保留自己的选中、草稿、历史与视口。

## 调用链与边界

`PanelIcon/openManagement → workflowEntrySession → views.management(sessionId) → showConversation → sidebarRight.openTab`；`WorkflowViews.session` 按会话保存 Store，`setWorkflowSidebarFullscreen` 只对当前、匹配标签且位于 dock 的命令目标生效。

当前实现并非早期“主页单独占中央 B”的方案：`main` 槽仅兼容转发，实际编辑器位于原生右侧栏。全窗、分栏与其他插件标签由 DSH 管理；Graphon 不参与。目标会话存在未提交需求时，关联会被拒绝，避免覆盖草稿。

# 撤销重做与自动保存

[返回总索引](../README.md) · [交互索引](./README.md)

更新日期：2026-10-17。本文按本轮保存实现核对；自动检查与本轮真实桌面待验收项见[迭代记录](../验证/11-保存高级设置与子Agent定义迭代.md)，不沿用旧自动保存节奏或旧实机结论。

## 入口与状态

- 左下「撤销 / 重做」及 Command/Control+Z、Shift+Command/Control+Z 操作图历史；输入框内原生文字撤销不由画布接管。
- 标题后的「保存」图标及 `⌘S / Ctrl+S` 保存；「另存为」及 `⌘⇧S / Ctrl+Shift+S` 创建独立副本。
- 保存按钮在写入和配置检查时显示旋转动效，完成恢复图标并提示“已保存”；标题状态点继续提供版本及状态说明，失败横幅提供「重试保存」。
- 原生「设置 → 工作流」可选择手动或自动模式。默认自动每 5 分钟保存有变化的流程；间隔为 1—1440 分钟整数，两种模式均可手动保存。

## 操作步骤

1. 编辑后按保存按钮/快捷键，或在自动模式等待设定间隔；普通画布变化不会反复弹“正在检查配置”。切换流程保留原来的保存保护；执行前无论哪种模式都先保存。
2. 撤销后可重做；新编辑清空 redo。图历史保存最近最多约 60 个编辑前快照。
3. 保存先持久化最新定义，再核对配置。缺少值的定义仍可保存；只有错误才展示警告。执行按钮可点，检查未通过时弹提示并引导处理，不创建运行记录。
4. 保存失败保留本地修改，修复问题后重试；失败时不能用未保存定义启动运行。
5. 另存为填写新名称后创建独立画布，保留节点、位置、便签、批注、普通变量值；Secret 只复制声明，需要在新流程重新配置和授权。

## 调用链与边界

`store.edit → renumberWorkflow → undo/redo + 未保存状态`；由按钮、快捷键、自动间隔或执行前的 `store.save()` 进入 `flush → api.save(snapshot, revision) → inspectReadiness`。不再对图编辑使用 500ms 防抖保存。保存草稿输入的内部防抖属于另一用途，不等于自动写入流程定义。

写入继续串行处理；保存等待中产生的新编辑用新 revision 再写，过期导航/列表响应不覆盖新草稿。执行启动需匹配当前保存与检查结果。另存为使用导入时的身份重建和凭据隔离契约，不复制历史运行或本机授权。

这是编辑器快照与 DSH 持久化，Graphon 不提供 UI Undo。当前没有面向用户的跨会话版本历史、差异合并或版本发布回滚页面；远端 Agent 变更只有本地干净时自动接入，并清空旧图历史。

# 缩略图

核验口径：2026-10-16 对当前源码作静态核对；相关自动测试已在本轮统一运行，结果见[验证报告](../验证/01-验证范围与结果.md)。本轮没有新增 Web/桌面全套手工复验。

## 入口与状态

- 右下「流程缩略图」可收起/展开；初次测得画布宽度至少 480px 时默认展示，面板导致剩余宽度过窄时收起。
- 缩略图用一张 Canvas 绘制节点和当前视野框，不为每个缩略节点建立 React 子树。
- 可点击、拖动、方向键定位；Shift 方向键移动更大范围，Home/Enter/空格回流程中心。

## 操作步骤

1. 展开缩略图，点击视野外位置使主画布居中到该点。
2. 拖动视野框或使用方向键平移，不改变当前缩放比例。
3. 用标题右侧减号收起；再次展开保留主画布当前位置。

## 调用链与边界

`MiniMap → miniMapTransform/worldToMiniMap/miniMapToWorld → centerViewport → onViewport`。投影范围包含整个图及当前视野，即使平移到空白区域仍可找回；拖动期间冻结映射，结束时重算，避免滑动反馈。

缩略图属于 UI 导航，不调度 Graphon。当前仅绘节点及视野，不画便签和每条边；不能把它当运行状态全图监控。

# 连线与分支出口

[返回总索引](../README.md) · [交互索引](./README.md)

核验口径：2026-10-16 对当前源码作静态核对；相关自动测试已在本轮统一运行，结果见[验证报告](../验证/01-验证范围与结果.md)。本轮没有新增 Web/桌面全套手工复验。

## 入口与状态

- 节点右侧是源出口；选中一个出口后，点击另一节点左侧入口连接。输入节点无入口，输出及退出循环节点无出口。
- IF、问题分类器、人工介入有多个独立出口。每行灰色说明在左，黑色粗体名称在右；完整内容保留在悬停说明中。
- 选择源出口后显示连接提示；Esc 或点击提示取消。

## 操作步骤

1. 点击源节点某个出口，再点击目标节点入口。
2. 同一源/目标/端口已存在时不重复添加；点击自身入口不连自身。
3. 点击连线选择它，再用删除键移除。删除一个分支配置时，相应旧出口连线一并清理。

## 调用链与边界

`nodePorts → Canvas 出口按钮保存 {id,port} → 入口按钮生成 WorkflowEdge → onEdit`。边保存的是稳定节点 ID 和分支端口 ID，不是显示编号。

`branchTop/nodeSize/portY` 是画布、连线缓存和导出共用几何。当前分支行节距 32px，改文字顺序不改变端口。Graphon 运行时处理激活、跳过和汇合；创建连线、显示出口与删除边是客户端工作。结构合法性仍以宿主校验为准；没有把“拖出端口自动建节点”记为已实现。

人工节点现在按原行动顺序、`default`（「常规继续」）、`timeout` 展示独立出口。「常规继续」在任一正常行动后与所选行动同时激活；超时只走 timeout。端口使用稳定 ID，旧配置中的同名保留端口不重复生成。

初次静态审计曾发现客户端缺少 default，面板改名也可能清掉合法默认边；当时没有执行该组件路径。当前已补齐端口并用真实 NodePanel 回归：改名保留显式/省略 port 的默认边，移除行动只清该行动边；画布可直接选择 default 连边。历史与修复入口见[人工默认出口记录](../验证/问题/04-人工默认出口契约.md)。这些组件回归不替代本轮完整 Web/桌面验收。

# JSON 导入导出与待处理

核对日期：2026-10-21。本文描述当前客户端和 Host 的操作逻辑；具体实机覆盖范围由验收记录说明。返回[交互索引](README.md)或[手册索引](../README.md)。

导入和导出只支持 [JSON 字段说明](../原理/10-JSON字段与导入导出.md) 中的当前结构：`formatVersion: 2`、Graphon `protocol: 1`。旧包版本或不支持的字段直接报错，不自动转换。JSON 文件和 ZIP 内的 `workflow.json` 遵守同一规则；不能只修改版本号来跳过字段校验。

导入后的工作流直接进入原有画布。缺少配置时，节点保留，标题后显示红色三角形，三角形中有白色“！”。画布右侧展示待处理清单。可以继续编辑、保存和再次打开，全部必需配置完成后才能运行，不另设草稿区。

## 1. 导入一份流程

1. 画布左工具栏点击“导入流程 JSON”图标，直接进入“导入 JSON / ZIP”；主页原导入入口保留。
2. 选择目标工作区；默认“导入为新流程”。需要覆盖时，明确选择目标流程。
3. 选择 `.json`、`.zip` 文件，或将 JSON 粘贴进内容框。
4. 点击“检查文件”。格式有效后展示流程信息和依赖情况。
5. 可以提前匹配模型、工具、角色或文件，也可以保留待配置项直接导入。
6. 点击“导入为新流程”。流程保存成功后关闭导入窗口，直接打开画布。

缺少资源不会导致节点被删除、流程重新生成或画布另开一个临时环境。格式损坏、身份冲突、非法连线和不允许的 Secret 字段仍会明确报错，不能通过“稍后处理”绕过。

导入前的依赖选择只是便利入口。用户改变映射后需要重新“检查文件”，避免把之前的检查结果用于另一份配置。导入动作本身也会由 Host 重新核验。

## 2. 处理画布上的红色提示

| 入口 | 显示与动作 |
| --- | --- |
| 节点标题后的红色三角 | 悬停显示待处理说明；点击进入对应配置。普通节点仍保持原位置与连线 |
| 容器标题后的红色三角 | 内部节点有问题时也会提示，避免必须先打开内部画布才能发现 |
| 画布右侧“N 项待处理” | 列出当前缺少值、资源不可用或执行配置不完整的原因 |
| 待处理消息条 | 点击定位对应节点或环境变量；内部节点会定位到所属容器画布 |
| 重新检查图标 | 重新读取当前 Host 能力；适合刚连接工具、切换模型或配置受保护凭据之后使用 |
| 清单展开/收起 | 只调整清单展示，未完成项目仍会阻止运行 |

清单中的文字会指明处理方式，例如“请选择模型”“角色预设不存在”“文件来源不存在”“环境变量缺少值”。普通编辑只标记未保存；保存、主动重新检查或执行前根据新定义和目标环境核对。配置正常不展示警告，不再因为每次移动节点显示“正在检查配置”。不能通过手工清空提示或关闭清单使流程变成可运行。

依赖属于独立子流程时，消息会指出子流程名称及关联调用节点。需要进入相应子流程修正其配置；主流程不会把子流程内部的问题当成已经解决。

## 3. 不同缺失项怎样处理

| 待处理项 | 处理位置 | 完成条件 |
| --- | --- | --- |
| 模型不存在或思考强度不兼容 | 节点模型配置；必要时先在 Harness 配置模型 | 当前宿主存在所选模型及有效配置，或有可用宿主默认模型 |
| 工具、MCP 不可用 | 节点工具配置和 Harness 的连接/权限入口 | 工具在当前对话或工作区可用，必需参数已配置 |
| Agent 身份未选择或定义缺失 | Agent 节点的“子 Agent”卡片 | 选择或新建工作流内定义；角色文本存入 `subAgents[].prompt`，节点通过 `config.subagentId` 引用 |
| 其他模型节点的角色预设缺失 | 节点角色选择 | 选择已有角色，或取消不需要的角色引用；Agent 节点不使用节点级 `rolePresetId` |
| 外部子流程不存在 | 调用节点的工具/子流程选择 | 目标工作区中存在正确流程，且它本身也完成配置 |
| 固定资料缺失 | 文档、知识或文件验收配置 | 选择目标工作区内有效文件；JSON 中的旧绝对路径不自动授权 |
| 普通环境变量缺值 | 左工具栏高级设置 → 环境变量 | 选择字符型或数字型并设置值；勾选“为变量设置值”后，空字符串和 0 也算已提供 |
| Secret 未配置或状态不可核验 | 环境变量面板中的受保护凭据管理入口 | 目标环境的原生保护能力、凭据状态和所需授权可核验 |
| URL、代码、分支条件等未完成 | 对应节点设置 | 满足该节点运行要求 |

高级设置入口使用图标按钮，悬停显示说明，内部为“环境变量 / 全局变量 / 执行策略 / 智能体预设”四个标签。全局变量页展示原有系统变量，由目标宿主生成，不需要用户逐项填写；缺少宿主支持的系统变量不能在 JSON 中伪造。执行策略页只配置输出修复策略、Agent 并发上限和最大修复轮次；旧字段的只读兼容规则见[JSON 第 8 节](../原理/10-JSON字段与导入导出.md#8-执行策略-executionpolicy)。

Secret 不在普通值输入框中填写。只保存变量声明，打开受保护入口后完成本机配置。没有可核验的保护能力时，相关节点继续提示待处理。

## 4. 保存与运行

可以带着待处理项保存流程，关闭后再次打开继续配置。画布本身就是尚未完成的流程，不需要把它移到另一列表。

“执行”按钮保持可点击。点击后先强制保存当前画布，再检查配置；保存按钮在写入及检查期间旋转。存在缺失值时弹出“请先处理缺失配置”，提示先按照画布右侧清单处理，再次点击执行。弹窗提供“关闭”和“去处理”；后者展开并聚焦待处理清单。流程定义已可保存，本次不会启动运行。

以下状态不能启动运行：

- 仍有必需配置待处理。
- 配置检查正在进行，尚未获得当前定义的结果。
- 检查失败，无法确认当前模型、工具、文件或受保护凭据状态。

后台检查中仍可点击“执行”发起一次新的检查。点击后检查期间只防止重复提交；检查失败则弹出原因和处理指引，不静默停留在灰色按钮。保存失败、正在处理其他操作以及已有运行等防重复限制仍保留。Host 在真正启动前还会重新检查，通过其他入口调用执行也不能绕过该检查。运行所需的用户输入和本次上传文件仍由运行询问入口收集，不把尚未开始的一次运行当成历史文件授权。

固定外部资料缺失时，需要先重新选择文件。如果资料由真实上游节点声明生成，且产物路径与读取路径完全对应，则允许在本次运行中提供，不要求用户预先创建空文件；路径边界和实际读取验证仍然有效。无依赖关系的其他节点声明了同名产物，不能替代配置。

## 5. 导出 JSON、完整流程包和说明

画布左侧的“导出”图标向右展开原生菜单：选择“流程 JSON”进入原导出面板，选择“画布 SVG”直接导出视图。JSON 面板中的完整资料包和 Markdown 说明功能保留。

| 导出选项 | 内容 | 适用情况 |
| --- | --- | --- |
| 下载 JSON / 复制 JSON | 主流程、可用的随包子流程、角色、变量声明、节点与画布编辑信息、依赖清单 | 分享流程模板；资料由接收方重新选择 |
| 下载完整流程包（含资料） | 相同的 `workflow.json`，加附件清单和允许附带的固定资料 | 在不同工作区或设备迁移流程与资料 |
| 导出 Markdown 说明 | 人类可读的流程说明 | 阅读、讨论或记录；不能把这份 Markdown 当成可执行导入文件 |
| 导出 SVG | 画布图形视图 | 展示或插入文档；不能恢复执行定义 |

“包含普通环境变量的值”默认不勾选。只有确认这些普通值可以分享时才勾选。Secret 值和本机授权始终不导出。提示词、角色、批注和资料是用户提供的内容，应在分享前自行检查。

JSON 最大 8 MB；完整流程包最大 32 MB，单个资料最大 8 MB，资料总量最大 16 MB。固定资料无法读取或超限时会给出原因，可以改用 JSON，导入后再选择资料。

上游尚未生成的资料可以通过 JSON 迁移产物声明与引用关系；ZIP 当前要求资料已经存在，因此会提示改用 JSON。长文件名会替换不安全字符并按最多 180 个 UTF-8 字节截断，导入时加上序号，文件内容不变。

JSON 导出超限会直接提示，不会继续下载一份本项目无法导入的文件。

## 6. 覆盖导入

“覆盖”是用户明确选择的导入方式，不是默认行为。检查文件后需要确认覆盖目标及其版本。目标在此期间被其他操作修改，Host 会拒绝使用旧版本覆盖；刷新覆盖版本、重新检查并确认后才能继续。

覆盖替换流程定义，原有运行快照保留。随包角色和子流程使用新的身份，避免按名字覆盖目标环境的其他资源。资料写入本次专用目录，不覆盖原文件。

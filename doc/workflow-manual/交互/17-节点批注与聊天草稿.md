# 节点批注与聊天草稿

[返回总索引](../README.md) · [交互索引](./README.md)

核验口径：2026-10-16 对当前源码作静态核对；相关自动测试已在本轮统一运行，结果见[验证报告](../验证/01-验证范围与结果.md)。本轮没有新增 Web/桌面全套手工复验。

## 入口与状态

- 选本层一个或多个节点，顶部「添加注释」进入放置模式，再点画布决定唯一蓝色序号位置；右键菜单按右键点位放置。
- 轻量白色胶囊输入上方是独立编号 chips、更多及加号；可搜索、增删本层引用、切换多条批注。
- 聊天输入区「N 条注释」和画布序号均可回改；提交只写聊天草稿，最后发送才交 Agent。

## 操作步骤

1. 选节点后放置标记，输入修改要求；Enter 提交草稿，Shift+Enter 换行，输入法选字 Enter 不提交。
2. 加号只列当前层未引用节点；要改子节点须进入子流程。本地显示局部编号，引用保留 stable ID。
3. 发送前仍可回改或删除；收到 DSH 原生准入回执后才清理对应批次序号，失败可保留重试。

## 调用链与边界

`Canvas.placeAnnotation → AnnotationPosition(world x/y + scopePath) → AnnotationEditor → chat.stageAnnotation → native input reference`。弹层优先靠标记右侧，不足向左，再做边界限制；Marker 不跟随节点移动。`enumerateAnnotationNodes` 限定本层，历史已选引用允许按 ID 全图解析。

`chat-bridge` 按会话/工作流/批次/修订关联准入回执，序列化只给 Agent stable ID 与要求，不发送临时序号/画布点位。它不直接调度 Graphon。批注与持久化便签是两种数据；草稿主要保存在 sessionStorage，不等于跨设备同步。

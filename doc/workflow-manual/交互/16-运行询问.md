# 运行询问

[返回总索引](../README.md) · [交互索引](./README.md)

核验口径：2026-10-16 对当前源码作静态核对；相关自动测试已在本轮统一运行，结果见[验证报告](../验证/01-验证范围与结果.md)。本轮没有新增 Web/桌面全套手工复验。

## 入口与状态

- 缺少必填输入时弹「补充运行所需信息」；人工介入时弹「等待人工处理」，展示工作流名、人工说明及行动按钮。
- 字段支持文本、段落、数字、布尔/选择、JSON、单文件/文件列表；隐藏字段不绘制。
- 「稍后补充」只收起本次询问，运行继续 waiting；「取消运行」才发取消命令。

## 操作步骤

1. 填写缺失字段；必填空白、文件读取失败或操作提交中不能继续。
2. 文件总大小客户端限制 2,000,000 字节，读取成带 name/mimeType/base64 的值。
3. 点击人工行动或「提交并继续」；记录页可再次点击「补充信息」恢复被关闭的询问。

## 调用链与边界

`run.status=waiting → questionKey(run.id/waitingExecutionId) → RunQuestion → store.answer → api.answer`。人工行动通过 `__action` 提交稳定行动 ID，宿主继续校验字段及分支。

询问框由客户端显示，人工等待状态及持久化恢复由 DSH 管理。当前暂停后释放 Python 执行，恢复按 DSH 已保存结果重建推进；不宣称持久化恢复 Graphon 原生帧。JSON 有提示但客户端没有独立 JSON 语法阻止按钮逻辑，最终校验在宿主。

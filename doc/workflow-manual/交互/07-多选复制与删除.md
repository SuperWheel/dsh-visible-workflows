# 多选复制与删除

[返回总索引](../README.md) · [交互索引](./README.md)

核验口径：2026-10-16 对当前源码作静态核对；相关自动测试已在本轮统一运行，结果见[验证报告](../验证/01-验证范围与结果.md)。本轮没有新增 Web/桌面全套手工复验。

## 入口与状态

- 指针模式点击节点选择；Shift 点击切换成员，空白拖框选择，Command/Control+A 选择本层全部节点。
- 选中表现为高亮边框，不使用勾选框。多选操作可从顶部或右键菜单进入。
- Delete/Backspace 删除当前所选便签、连线或节点；运行中修改动作禁用。

## 操作步骤

1. 使用 Shift 或框选建立集合；单击未拖动节点可打开配置。
2. 点击「复制节点」克隆所选子图，只复制两端均在集合中的边，并为嵌套节点重新生成身份。
3. 删除节点会删除关联边；连接到该节点的便签解除连接并保留内容。

## 调用链与边界

`Canvas.begin/end → onSelect`；`duplicate → copyNodes → remapNodeConfig → placeWithoutOverlap`；`remove → onEdit`。重映射只处理变量引用，不改字段名或普通叙述中的相同文本；输入、vars、item、index 保留其作用域含义。

多选与复制是 UI 图编辑，不由 Graphon 执行。复制不是系统剪贴板导入/导出；当前没有跨应用粘贴完整工作流的承诺。

# 模型与思考强度

[返回总索引](../README.md) · [交互索引](./README.md)

核验口径：2026-10-16 对当前源码作静态核对；相关自动测试已在本轮统一运行，结果见[验证报告](../验证/01-验证范围与结果.md)。本轮没有新增 Web/桌面全套手工复验。

## 入口与状态

- LLM、Agent、分类器、参数提取器及 Agent 文档解析节点显示模型设置。
- 默认「跟随 DSH」，没有插件独立 API Key 配置；可以指定宿主模型及其支持的思考强度。
- 模型目录失败或原模型不在目录时保留已有配置并解释原因；不静默切成目录第一个模型。

## 操作步骤

1. 保持「跟随 DSH」，运行时优先当前对话模型，否则宿主默认模型。
2. 需要逐节点覆盖时选择具体模型，再选择其支持的强度；不支持的旧值明确标记。
3. 执行前确认错误提示；运行中该面板禁用修改。

## 调用链与边界

`store.load → api.models → ModelSettings` 只管理模型引用和强度字符串；运行开始的实际模型/强度解析由 DSH 宿主完成并冻结到运行上下文。

Graphon 调度节点，但不自行读取宿主凭据或提供模型目录。模型调用是否成功依赖 DSH 已有配置、可用性与权限；本次未调用真实模型。Agent 自动建图的默认模型/强度上限由宿主 Agent 保存逻辑另行约束，不由此下拉框猜测。

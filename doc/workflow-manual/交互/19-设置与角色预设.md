## 入口与状态

- DSH 原生「设置 → 工作流」显示保存偏好和角色预设管理；节点内「管理角色预设」打开同一原生分类。
- 支持搜索、新增、点击卡片编辑、删除和加载重试。预设仅含角色提示词及名称，不携带模型、强度或工具权限。
- 预设库新增/修改在设置中进行。Agent 节点把预设选择放在子 Agent 卡片，选择时复制角色文本快照；卡片可直接编辑自己的角色文本。其他模型节点保留只读预设提示词。

## 操作步骤

1. 在设置新增名称和角色提示词，保存；名称或提示词为空时不能保存。
2. 回节点选择预设。普通模型节点未来运行使用最新预设；Agent 的子 Agent 定义保留选择时的快照，预设变化后需点击“更新预设内容”才同步。
3. 运行已开始时保持该次提示词快照；删除或错误在宿主保存路径处理，不从面板静默替换其他预设。

## 调用链与边界

`openNativeSettings → settings.section(visible-workflows) → WorkflowSettingsSection → presets/savePreset/deletePreset`。`llm`、`classifier`、`extractor`、`document` 节点可保存 `rolePresetId`；Agent 节点只通过 `subagentId` 引用定义，其定义保存角色文本及本地预设来源。Agent 节点不接受节点级 `rolePresetId`，不会在打开或保存时自动转换字段。

设置导航、CRUD 与运行提示词快照属于 DSH/插件，Graphon 不提供角色库。2026-10-17 新增手动/自动保存与间隔，默认自动每 5 分钟；画布高级设置现有“环境变量 / 全局变量 / 执行策略 / 智能体预设”四个标签。“执行策略”只配置输出修复策略、Agent 并发上限（1–8，默认 3）和最大修复轮次（0–2，默认 2，0 表示关闭），用于后续新运行。自动修复仍须宿主确认授权，编辑配置不能授予权限；旧字段只读保留且不生效，见[JSON 执行策略](../原理/10-JSON字段与导入导出.md#8-执行策略-executionpolicy)。当时的新增交互验收状态见[历史迭代记录](../验证/11-保存高级设置与子Agent定义迭代.md)。

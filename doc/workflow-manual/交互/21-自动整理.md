# 自动整理

[返回总索引](../README.md) · [交互索引](./README.md)

核验口径：2026-10-16 对当前源码作静态核对；相关自动测试已在本轮统一运行，结果见[验证报告](../验证/01-验证范围与结果.md)。本轮没有新增 Web/桌面全套手工复验。

## 入口与状态

- 左侧「整理画布」在非运行状态可用，对当前画布层级整理。
- 容器、普通节点及长分支卡片按真实宽高布局；关联便签随整理重新安排，游离便签保留位置。
- 整理结束自动适应当前可见区域；这是一次可撤销图编辑。

## 操作步骤

1. 返回要整理的主图或子图，点击整理。
2. 检查连线和说明；需要恢复原位置时使用撤销。
3. 已连接便签排在锚点下方，并尽量避开节点、游离便签和其他说明卡。

## 调用链与边界

`Canvas.arrange → arrangeNodes → arrangeAttachedNotes → onEdit → fit`。DAG 按依赖层级分列，列宽取该列真实最大宽度，竖向使用节点真实高度；无效循环图走有限 fallback 列保持可见，不在布局中死循环。

整理不改变节点 ID、端口、执行条件或 Graphon 调度，只改变画布坐标。它不是复杂图的最优交叉边最小化算法；格式正确与运行可执行仍需宿主校验。

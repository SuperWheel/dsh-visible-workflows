## 入口与状态

- 左侧「添加便签」创建持久化说明卡；当前仅主流程支持添加，子流程入口禁用并提示返回主流程。
- 浮动工具栏提供编辑、颜色、连接节点、删除；双击正文也可编辑，顶部细条拖动，选中后右下调整尺寸。
- 支持标题、粗体、行内代码、有序/无序列表的安全子集，不执行 HTML 或链接。

## 操作步骤

1. 新建后编辑正文，失焦或 Command/Control+Enter 保存；Esc 取消本次文字修改。
2. 连接当前层节点后，节点移动多少，便签跟随相同位移；手动移动便签建立新的相对偏移。
3. 改颜色、调整大小或删除；删除锚点只解除连接并保留便签，自动整理重新安排已连接便签。

## 调用链与边界

`StickyNote → onChange/onDragStart/onResizeStart → Canvas → onEdit`；`moveAttachedNotes/arrangeAttachedNotes` 管理偏移；`parseNoteContent` 同时服务 React 显示和 SVG 导出。

便签是 Workflow.notes 的说明，不是可执行边或节点，不进入 Graphon。宽高限制 160–1200 / 100–900，正文最多 20,000 字符；运行中禁用修改。不是完整 Markdown 编辑器或多人评论系统。

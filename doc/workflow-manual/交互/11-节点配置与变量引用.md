# 节点配置与变量引用

[返回总索引](../README.md) · [交互索引](./README.md)

核验口径：2026-10-16 对当前源码作静态核对；相关自动测试已在本轮统一运行，结果见[验证报告](../验证/01-验证范围与结果.md)。本轮没有新增 Web/桌面全套手工复验。

## 入口与状态

- 点击节点打开右侧配置；可改节点名、固定状态，在「设置 / 上次运行」之间切换，说明图标提供帮助。
- `SpecificConfig` 按种类显示输入字段、条件、分类、人工按钮、容器、代码、文档、HTTP、列表与工具参数等。
- 「可引用的变量」为来源标题＋浅灰字段卡，显示名称、类型、说明与复制引用；无声明/真实输出时不伪造通用字段。

## 操作步骤

1. 选中节点，修改其配置；迭代/循环通过「编辑内部流程」进入子图。
2. 展开变量卡，复制完整 `{{stable_node_id.field}}` 或作用域变量，粘贴到支持引用的配置。
3. 删除分类/行动/条件出口后检查连线；面板保存会移除已不存在出口的边。

## 调用链与边界

`NodePanel.patch/config → editScoped/replaceGraph → store.edit`。`availableNodes` 只提供本层和祖先层已经连通的依赖，不泄漏另一个容器内部节点；输入变量来自声明，字段来自节点契约或最近成功运行元数据。

变量卡是 Schema/引用说明，不展示本次实际值；上次真实值见运行详情。手写或 Agent/API 配置也受宿主可执行预检和运行守卫约束：仅允许依赖祖先及当前局部作用域，已知越界节点不能靠默认值绕过。未知缺失值保留原有可选/失败兜底，见[变量与稳定身份](../原理/07-变量与稳定身份.md)。UI 展示局部编号，引用和持久化仍依赖稳定 ID。固定只保护 Agent 保存路径，用户仍能手动画布修改或解除；Graphon 不负责配置表单和保护按钮。

核验口径：2026-10-16 对当前源码作静态核对；相关自动测试已在本轮统一运行，结果见[验证报告](../验证/01-验证范围与结果.md)。本轮没有新增 Web/桌面全套手工复验。

## 入口与状态

- 左侧加号打开「节点 / 工具 / 开始 / Snippets」。搜索匹配节点名称和说明；方向键、Home/End 可切标签，Esc 关闭目录。
- Agent 行先展开「工具调用 Agent」，点击「添加」才真正创建。
- 「开始」中的用户输入已有时禁用；「退出循环」仅在循环范围内可见。

## 操作步骤

1. 点击加号，选择节点分组或搜索名称。
2. 点击节点后在当前视野附近找不重叠位置，选中新节点并打开配置。
3. 迭代/循环节点通过「编辑内部流程」进入子图；修改子节点须先进入该子图。

## 调用链与边界

`NodePicker → Canvas.add → newNode/initialConfig → placeWithoutOverlap → onEdit → store.edit`。目录提供节点类型和初始配置，实际执行语义由宿主节点适配器与 Graphon 调度配合；“能添加”不等于当前配置已满足运行校验。

未接通：定时触发器、Webhook 订阅；Snippets 当前仅为空状态，没有保存/导入片段库。目录没有 Dify Marketplace 安装流程。

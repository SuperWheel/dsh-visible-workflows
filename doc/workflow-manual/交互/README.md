## 实现归属

- 客户端：画布、编辑、导航、选择、布局、批注、便签、代码/提示词与运行结果展示。
- DSH 宿主：数据保存、模型目录和模型调用、工具权限、Agent 工具、询问恢复、会话及原生侧栏。
- Graphon 桥接：流程依赖、边激活、分支跳过和汇合。不能把上述界面功能或所有节点适配器记为 Graphon 内置能力。

## 明确未接通或不应过度宣称

- 定时/Webhook 触发订阅、Snippets 库、Dify Marketplace 安装。
- Dify 式发布/部署、可浏览版本历史与差异回滚；SVG 是视图导出。可执行流程的 JSON / ZIP 导入导出另见[导入导出与待处理](./23-JSON导入导出与待处理.md)，两者用途不同。
- 专门的规划进度与澄清 UI 尚未接通；当前生成/修改已接入[规划后端](../规划引擎/README.md)，候选最多两轮修正并沿用已有提案交互。真实模型及安装后的完整体验仍待验收，不能把候选修正、业务输出修复和改图续跑视为同一机制。
- 当前知识来源、解析器、工具和模型能力以 DSH 适配器为准，不能从目录名称推断等同 Dify 全套服务。
- [桥接协议](../../../runtime/graphon_bridge/README.md) 明确不宣称 Graphon 原生循环/迭代或原生帧持久化恢复。
- [人工节点 default 出口](./06-连线与分支出口.md) 的客户端/宿主契约差异已修复，补充真实配置组件保边及画布连边回归；原始静态审计保留于[问题记录](../验证/问题/04-人工默认出口契约.md)，实机验收另行记录。

## 测试覆盖边界

Canvas/Store/编辑器/批注/导航/工具目录已有针对性自动测试；主页卡片管理、预设 CRUD、运行询问表单和浏览器下载的完整 UI 路径仍需单独人工或端到端复验。各页列出具体证据及缺口，不将测试文件存在写作本次通过。
